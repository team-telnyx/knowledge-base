# DID Number Requirements for Chile

In order to purchase a Chile number you will need to provide the following:

## **Local Numbers in Chile**

For **personal identity** verification:

\* Name, last name

\* Passport or ID copy

For **business identity** verification:

\* Name, last name of an authorized representative

\* Company name

\* Passport or ID copy of an authorized representative

For **address** verification:

\* Address Worldwide (street, building number, postal code, city and country)

## **Toll-Free Numbers in Chile**

For **business identity** verification:

\* Name, last name of an authorized representative

\* Company name

\* Passport or ID copy of an authorized representative

For **address** verification:

\* Address Worldwide (street, building number, postal code, city and country)

\*Business use required: Business use is required, private use is not allowed.

## **National and Shared Cost Numbers in Chile**

For **personal identity** verification:

\* Name, last name

\* Contact phone number

\* Email address

\* Passport or ID copy

For **business identity** verification:

\* Company name

\* Contact phone number

\* Email address

\* TAX/RUT number

\* Company registration certificate

For **address** verification:

\* Address Worldwide (street, building number, postal code, city and country)
