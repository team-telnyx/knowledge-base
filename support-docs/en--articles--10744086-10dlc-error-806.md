# 10DLC Error (806): Unable to verify, needs compliant and accurate CTA information. Update with specific path for mobile opt-in, HELP instructions, STOP instructions, message frequency disclosure, "message and data rates may apply" disclosure and link to the message program privacy policy, or language referring to the privacy policy. (806)

If you receive this error it relates to the Message Flow field where everything about the opt in workflow is described and shown.

In plain english this error means that "We checked your message flow and it either did not sufficiently document or contain a compliant opt in process. Please make sure that the opt in path is clear and the opt in method has the required disclaimers.

Please change your message flow so it follows one of these formats: <https://support.telnyx.com/en/articles/10562019-guide-to-10dlc-message-flow-field>

Please change your opt in form so it contains all the necessary disclaimers:

<https://support.telnyx.com/en/articles/10684260-10dlc-opt-in-form>
