# Brazil Number Porting

Here you will find a detailed list of requirements for Brazil number… See Telnyx guidance and requirements.




## Local / National / Toll-Free

1. LOA (CPF / CNPJ required).
2. ID / Passport copy
3. Company Registration certificate
4. Latest Invoice

## Download Brazil letter of authorization

You can download the Brazil LOA **[here](https://www.dropbox.com/s/fmli59wv3wfky7w/BrazilLOA.pdf?dl=0)**.

**> Once your port request is in status *FOC confirmed*, we require at least 48 business hours prior FOC date to change the date.**

## Porting Hours

**Standard time after 5 PM local**

## Expected Timeframes

|  |  |
| --- | --- |
| Number Type | Expected Timeframe |
| National | 5+ Business days |
| Toll-Free | 5+ Business days |

**Note:** These are typical processing times. Actual times may vary based on the losing carrier.
