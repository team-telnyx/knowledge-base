# How to Pick a Toll Free Use Case

When submitting a Toll Free Verification Request this is how you select a Use Case

K

Written by Klane Pedrie

October 23, 2025

How to Pick a Toll Free Use Case

Most Verification Requests fall into one or more of these use cases. If you have more than 1 use case then select "Mixed". If you have any non-marketing content and also marketing content then select "Mixed".

* 2FA: To send a one time code such as at login.
* App Notifications: Notifications such as "Your password has been reset".
* Booking Confirmations: Confirmation such as "Your stay has now been booked at the Telnyx Hotel in Denver, CO for Jan 1st, 2028."
* Conversational / Alerts: This is a large catch all that should be used for any 1 on 1 texting such as customer service.
* Courier Services & Deliveries: "Your order has been delivered by FedEx at 12:00pm."
* Fundraising: Any charity messaging that will solicit donations.
* General Marketing: Any promotions, quotes, or offers made to customers.
* Mixed: 2 or more of the other use cases.
* Order Notifications: "Your order number is 123456, please pick up at counter 3 in 15 minutes."
* Political: Any content promoting a political candidate or soliciting donations for political candidates.
* System Alerts: "Fridge 3 is over the temperature threshold."
