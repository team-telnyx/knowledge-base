# Bulk Edit Numbers - Assigning tags

Editing numbers should be easy, in this article we will explain how to assign tags in bulk.

Written by Shubam

April 16, 2026

Table of contents

# Guide to Assigning Tags in Bulk

**A step-by-step guide to bulk edit Tags settings of selected numbers**

## **Step 1**

Log in to your Telnyx Mission Control account and click on the Real-Time Communications option and after click on Numbers option on the left side of the page.

[![](https://downloads.intercomcdn.com/i/o/ltcafuzd/2280244636/36ef58a01443405e92a769ec6597/image.png?expires=1781167500&signature=baaa3c01b874bcb5fe00c5bc3c7ed4c0280c67bb38adac03c585f556d99dbf30&req=diIvFst6mYdcX%2FMW1HO4zcZ7bqvhemLciHY1zbXAa9u05CAGLTuzAEd2uAiS%0AWiQQEngCbdNcdbP%2Bndc%3D%0A)](https://downloads.intercomcdn.com/i/o/ltcafuzd/2280244636/36ef58a01443405e92a769ec6597/image.png?expires=1781167500&signature=baaa3c01b874bcb5fe00c5bc3c7ed4c0280c67bb38adac03c585f556d99dbf30&req=diIvFst6mYdcX%2FMW1HO4zcZ7bqvhemLciHY1zbXAa9u05CAGLTuzAEd2uAiS%0AWiQQEngCbdNcdbP%2Bndc%3D%0A)

## **Step 2**

Click on the [Manage Numbers](https://portal.telnyx.com/#/numbers/my-numbers) option

## **Step 3**

Select the numbers by selecting checkboxes in front of the numbers you'd like to edit.

[![](https://downloads.intercomcdn.com/i/o/ltcafuzd/2280284896/da911e9706b9903421730529c050/Design+sem+nome+%284%29.png?expires=1781167500&signature=5d31afe7bd7d78725de9dff9587fd52f5d61b730a5a9375f241400c996cc4f25&req=diIvFst2mYlWX%2FMW1HO4zbyIMo1bVSuz%2FD4yNeZMAEFAAu4imnkYe8z%2BkW%2Bd%0A%2BdHxiYURO8KLxkvcQjA%3D%0A)](https://downloads.intercomcdn.com/i/o/ltcafuzd/2280284896/da911e9706b9903421730529c050/Design+sem+nome+%284%29.png?expires=1781167500&signature=5d31afe7bd7d78725de9dff9587fd52f5d61b730a5a9375f241400c996cc4f25&req=diIvFst2mYlWX%2FMW1HO4zbyIMo1bVSuz%2FD4yNeZMAEFAAu4imnkYe8z%2BkW%2Bd%0A%2BdHxiYURO8KLxkvcQjA%3D%0A)

## **Step 4**

You can also select all the numbers displayed on the page by using the checkbox above the top number.

[![](https://downloads.intercomcdn.com/i/o/ltcafuzd/2280296070/be97ef6c6e73e6b8d65a1d96ae25/Design+sem+nome+%285%29.png?expires=1781167500&signature=3e66b9a436c991c07fdee09db0c101315030137ab487a40a1cb292e36c713414&req=diIvFst3m4FYWfMW1HO4zb6OGXWbIhZW9BphL5E7DnecuQRiwhTnfeTKIIh6%0A%2FisHk3J9F6aTuwS0T%2Bg%3D%0A)](https://downloads.intercomcdn.com/i/o/ltcafuzd/2280296070/be97ef6c6e73e6b8d65a1d96ae25/Design+sem+nome+%285%29.png?expires=1781167500&signature=3e66b9a436c991c07fdee09db0c101315030137ab487a40a1cb292e36c713414&req=diIvFst3m4FYWfMW1HO4zb6OGXWbIhZW9BphL5E7DnecuQRiwhTnfeTKIIh6%0A%2FisHk3J9F6aTuwS0T%2Bg%3D%0A)

**Note - You can expand the selection by increasing the Row count of the displayed page ranging from 10-100 numbers displayed on the page.**

## **Step 5**

Once you have selected your desired numbers, click on the Bulk Actions dropdown and select Edit Tags.

[![](https://downloads.intercomcdn.com/i/o/ltcafuzd/2280301408/66ac508394bffdfb407c73125b51/Design+sem+nome+%286%29.png?expires=1781167500&signature=1b58eaab923b824a26b743d5721896c32a560e1c59a203d35a6e8278f9e34381&req=diIvFsp%2BnIVfUfMW1HO4zYZSch5cK5H9%2B0AY9AqNAqEJ6JalErjSkuNWJ4r6%0Ac3U39SWtkwCFIXhEw8w%3D%0A)](https://downloads.intercomcdn.com/i/o/ltcafuzd/2280301408/66ac508394bffdfb407c73125b51/Design+sem+nome+%286%29.png?expires=1781167500&signature=1b58eaab923b824a26b743d5721896c32a560e1c59a203d35a6e8278f9e34381&req=diIvFsp%2BnIVfUfMW1HO4zYZSch5cK5H9%2B0AY9AqNAqEJ6JalErjSkuNWJ4r6%0Ac3U39SWtkwCFIXhEw8w%3D%0A)

After clicking **Edit Tags**, a new window will appear where you can select an existing tag that has already been created, or create a new tag by entering a name, such as **test-tag**, as shown in the screenshot.

## **Step 7**

You can also remove tags in bulk from the selected numbers. Just follow step 5 to access the **Bulk Edit Tags** option.

[![](https://downloads.intercomcdn.com/i/o/ltcafuzd/2282867276/231e3e7e1e634336d637461aae97/Design+sem+nome+%2811%29.png?expires=1781167500&signature=aa5d514eb9de838f9ae289fabed1cc63883f90066abd130159dcf22fdd908440&req=diIvFMF4moNYX%2FMW1HO4zd3It0hXL452PhaxeLGe1Zpqw%2FtXrBeFWujF7QqZ%0AFcV%2FB20gsmosRVr5fdo%3D%0A)](https://downloads.intercomcdn.com/i/o/ltcafuzd/2282867276/231e3e7e1e634336d637461aae97/Design+sem+nome+%2811%29.png?expires=1781167500&signature=aa5d514eb9de838f9ae289fabed1cc63883f90066abd130159dcf22fdd908440&req=diIvFMF4moNYX%2FMW1HO4zd3It0hXL452PhaxeLGe1Zpqw%2FtXrBeFWujF7QqZ%0AFcV%2FB20gsmosRVr5fdo%3D%0A)

Write the tag name that you would like to remove from selected numbers and then save it.

[![](https://downloads.intercomcdn.com/i/o/ltcafuzd/2280296070/be97ef6c6e73e6b8d65a1d96ae25/Design+sem+nome+%285%29.png?expires=1781167500&signature=3e66b9a436c991c07fdee09db0c101315030137ab487a40a1cb292e36c713414&req=diIvFst3m4FYWfMW1HO4zb6OGXWbIhZW9BphL5E7DnecuQRiwhTnfeTKIIh6%0A%2FisHk3J9F6aTuwS0T%2Bg%3D%0A)](https://downloads.intercomcdn.com/i/o/ltcafuzd/2280296070/be97ef6c6e73e6b8d65a1d96ae25/Design+sem+nome+%285%29.png?expires=1781167500&signature=3e66b9a436c991c07fdee09db0c101315030137ab487a40a1cb292e36c713414&req=diIvFst3m4FYWfMW1HO4zb6OGXWbIhZW9BphL5E7DnecuQRiwhTnfeTKIIh6%0A%2FisHk3J9F6aTuwS0T%2Bg%3D%0A)
