# Spain: SMS Guidelines

Sending SMS to Spain? See Telnyx guidance and requirements Learn more about Spain: SMS Guidelines with Telnyx.


Updated today


## **Spain: SMS Guidelines**

**MCC:** 214
​**Dial Code:** 34
​
Spain's telecoms regulator, the CNMC, is rolling out a new Alias Registry as part of Circular 1/2026. Starting September 15**, 2026**, any alphanumeric Sender ID — that's the brand name people see instead of a phone number when they receive an SMS — must be registered before it can be used to send messages to Spanish numbers (+34).
​
​**Information on Alphanumeric Sender ID registration:**
​
Please provide the details below to [alpha\_sender\_id@telnyx.com](mailto:alpha_sender_id@telnyx.com):
​
​*Your company details*
— Full legal company name
— Your NIF/CIF (Spanish tax ID for companies) or EU-VAT number if you're based outside Spain
— Registered company address

1. *Legal representative*
   — Full name
   — NIF or passport number
   — Mobile number and email address
   ​
2. *Sender ID details* (one set per alias)
   — The exact alias as it appears in your messages (e.g. MYBRAND)
   — What you use it for (transactional, OTP, marketing, etc.)
   — Planned start and end date — note that registrations are valid for a maximum of 24 months
   ​
3. *Proof of ownership* — one of the following per alias:
   — Trademark or trade name → certificate from OEPM (Spain) or EUIPO (EU)
   — Company name → certificate from the Spanish Mercantile Registry
   — Domain name → proof of ownership of a .es or ICANN-registered domain that matches the alias
   ​

Please make sure to always refer to our [Acceptable Use Policy for Messaging](https://support.telnyx.com/en/articles/1310359-acceptable-use-policy-for-messaging).
