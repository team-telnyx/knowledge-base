# Cyprus Number Porting

List of requirements for Cyprus number portability: Ensure your numbers are portable with this info. See Telnyx guidance and requirements.




## **Cyprus Number Porting**

**Local Number types**

1. LoA (with Local address)
2. Latest Invoice with the current carrier
3. Company Registration (if the number belongs to a company)
4. ID or Passport Number of the legal representative
5. Proof of address

**National and Toll-Free Number types**

1. LoA (with National address)
2. Latest Invoice with the current carrier
3. Company Registration (if the number belongs to a company)
4. ID or Passport Number of the legal representative
5. Proof of address
