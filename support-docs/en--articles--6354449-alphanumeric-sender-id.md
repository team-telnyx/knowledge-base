# **Global Messaging - Alphanumeric Sender ID Capabilities**

Depending on what your intended destination might be, there are different restrictions to take into account for your SMS traffic if using [Alphanumeric Sender IDs](https://developers.telnyx.com/docs/messaging/messages/alphanumeric-sender-id).

In some instances, Alphanumeric Sender IDs will be maintained, in others it might change and be overwritten to ensure delivery. In some cases your Sender ID will need to be pre-registered before use.

At Telnyx we try to make sending SMS globally as simple as possible, therefore customers can always submit using an Alphanumeric Sender ID and we will make any necessary adjustments to ensure delivery

Below you can find a compilation of guidelines and restrictions by country that state what can happen to your Alphanumeric Sender ID. Important to note that due to the fast-paced changes in the industry, the information below is subject to change without notice.
