# New Zealand Number Porting

Port your New Zealand phone numbers to Telnyx. This guide covers requirements, timelines, and the porting process for local and national numbers in New Zealand.

## Portable Number Types

|  |  |
| --- | --- |
| Number Type | Portable |
| Local Numbers | ✅ Yes |
| National Numbers | ✅ Yes |
| Toll-Free Numbers | ✅ Yes |
| Mobile Numbers | ❌ Not available |

## Expected Timeframe

Typical processing time from submission to FOC (Firm Order Commitment):

|  |  |
| --- | --- |
| Number Type | Expected Timeframe |
| Local / National / Toll-Free | 5–10 business days |

**Note:** Actual times may vary based on the losing carrier's responsiveness.

## Document Requirements

|  |  |
| --- | --- |
| Document | Details |
| **LOA** | Letter of Authorization signed by the authorized person |
| **Latest Invoice** | From current carrier, dated within the last 30 days |
| **Contact Details** | Full contact information for the authorized person |
| **Local Address** | Address within New Zealand is required |

### For Personal Accounts

* Full name
* Contact phone number
* Local address within New Zealand

### For Business Accounts

* Full name of authorized person
* Contact phone number
* Company name
* Local address within New Zealand

## Before Completing the LOA

* Save in PDF format (non-editable)
* Fill in all required fields completely
* Ensure information matches your current carrier's records exactly
* Include a valid New Zealand address

## Porting Process

1. Gather all required documents
2. Submit port request through [Mission Control](https://portal.telnyx.com)
3. Upload LOA and invoice
4. Telnyx submits request to the losing carrier
5. Receive FOC confirmation with activation date
6. Numbers activate on the scheduled FOC date
