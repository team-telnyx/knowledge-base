# DID Number Requirements for Jamaica

In order to purchase a Jamaica number you will need to provide the following:

## **Local Numbers in Jamaica**

For **personal identity** verification:

\* Signed LOI (within 1 month)

For **business identity** verification:

\* Signed LOI (within 1 month)  
​

For **address** verification:

\* Address Worldwide (street, building number, postal code, city and country)

## **Toll-Free Numbers in Jamaica**

For **personal identity** verification:

\* Name, last name

\* Signed LOI (dated within 1 month)

For **business identity** verification:

\* Company name

\* Signed LOI (dated within 1 month)

For **address** verification:

\* Address Worldwide (street, building number, postal code, city and country)
