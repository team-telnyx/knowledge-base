# Peru Number Porting

Here you will find a list of the requirements for Peru number portability.

Written by Paul Cross

February 10, 2026

Table of contents

# Local / National Numbers

1. LOA
2. Attorney's authorization for the representative (if the number belongs to a company)
3. ID / Passport copy
4. Company Registration certificate
5. Latest Invoice

## Download the Peru Letter of Authorization

Download the porting form [here](https://www.dropbox.com/s/0j3d2r4e5idm9o7/Peruvian_Porting_Form.pdf?dl=0).

## Porting Hours

**Standard time 00:00 AM to 4 AM Local**

## Expected Timeframes

|  |  |
| --- | --- |
| Number Type | Expected Timeframe |
| Local | 2-7 Business days |

**Note:** These are typical processing times. Actual times may vary based on the losing carrier.
