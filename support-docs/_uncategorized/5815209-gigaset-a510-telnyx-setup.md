# Gigaset A510: Telnyx Setup

Learn how to use your Telnyx account to set up and configure a SIP profile on the Gigaset A510 IP phone

The Gigaset A510 IP is an exceptionally versatile VoIP phone with the ability to make up to 3 parallel calls, either via Internet or traditional landline. It allows a caller to switch between 2 VoIP calls and 1 fixed line call at the press of a button.

## 1. Get your device's IP address and log into the Gigaset phone's web portal

In this step, you'll obtain the IP address from your A510, which you'll need to log into the web portal in the next step.

1. Press the paging button on your device's base station. This will display the device's IP address. Take note of this as you'll need it next.

   [![Paging button. ](https://downloads.intercomcdn.com/i/o/434928795/82d3ddcc9f453ce8725fae5d/1.png?expires=1781168400&signature=5129a3d6588f3c309211c548c59506948881067e780f01aef7443591c4a87d7e&req=cCMjH8t2mohaFb4f3HP0gMrurhwMc62kC5g9eIQoi0k5HC0wyfRoC0WUFe1i%0A0iU%3D%0A)](https://downloads.intercomcdn.com/i/o/434928795/82d3ddcc9f453ce8725fae5d/1.png?expires=1781168400&signature=5129a3d6588f3c309211c548c59506948881067e780f01aef7443591c4a87d7e&req=cCMjH8t2mohaFb4f3HP0gMrurhwMc62kC5g9eIQoi0k5HC0wyfRoC0WUFe1i%0A0iU%3D%0A)
2. On a computer connected to the same network as your phone, open a browser and type *http://* followed by the IP address you obtained in step 1.
3. The first screen that appears will require you to enter a system PIN. The default PIN for all new devices is *0000.*

   [![System PIN addition section. ](https://downloads.intercomcdn.com/i/o/434930481/0df25e14310f3a77798f12fc/3.png?expires=1781168400&signature=9223c86a41c7bef6fbb0c16a627a88a966eb4ebd756abfe6a6994a03916e4b3d&req=cCMjH8p%2BmYleFb4f3HP0gAh06Ot1iIF7luEXfAuo7uBwuYxtYz99EgmajW2t%0AgU0%3D%0A)](https://downloads.intercomcdn.com/i/o/434930481/0df25e14310f3a77798f12fc/3.png?expires=1781168400&signature=9223c86a41c7bef6fbb0c16a627a88a966eb4ebd756abfe6a6994a03916e4b3d&req=cCMjH8p%2BmYleFb4f3HP0gAh06Ot1iIF7luEXfAuo7uBwuYxtYz99EgmajW2t%0AgU0%3D%0A)
4. Click **OK**.

## 2. Configure your IP phone

1. From here, click on the **Settings** tab at the top of the page.

   [![Settings tab section of the Gigaset. ](https://downloads.intercomcdn.com/i/o/434930943/7a642cc9d3d1dc5ab4189ad2/4.png?expires=1781168400&signature=62b3178fb3d47848ae5ef926a4977a2c02dc029defcd849121cb9fb733bd18cb&req=cCMjH8p%2BlIVcFb4f3HP0gIVCMqBXWYKh%2Fwu3PSWRRZdFKJb6n2aKwRBi4j3e%0AM%2FI%3D%0A)](https://downloads.intercomcdn.com/i/o/434930943/7a642cc9d3d1dc5ab4189ad2/4.png?expires=1781168400&signature=62b3178fb3d47848ae5ef926a4977a2c02dc029defcd849121cb9fb733bd18cb&req=cCMjH8p%2BlIVcFb4f3HP0gIVCMqBXWYKh%2Fwu3PSWRRZdFKJb6n2aKwRBi4j3e%0AM%2FI%3D%0A)
2. Click on the **Telephony** link on the left-hand navigation to expand this menu. Click on **Connections** in the **Telephony** sub-menu and click **Edit** next to the line you want to configure.

   [![Connections section in the Telephony hub. ](https://downloads.intercomcdn.com/i/o/434932893/3711bad4302253d84c68f224/6.png?expires=1781168400&signature=a8b30f2466e9d48e4b91a43300893f700e40698c1b4b9c8c3d1315cc837a7dd6&req=cCMjH8p8lYhcFb4f3HP0gAjMNTF9SGDfyq%2F46GBUOqSo9SURXi3XKh9xUekA%0AIRQ%3D%0A)](https://downloads.intercomcdn.com/i/o/434932893/3711bad4302253d84c68f224/6.png?expires=1781168400&signature=a8b30f2466e9d48e4b91a43300893f700e40698c1b4b9c8c3d1315cc837a7dd6&req=cCMjH8p8lYhcFb4f3HP0gAjMNTF9SGDfyq%2F46GBUOqSo9SURXi3XKh9xUekA%0AIRQ%3D%0A)
3. Enter the following information:

   1. **Connection Name or Number:** Create a connection name suitable for your connection.
   2. **Connection Name or Number:** Choose a name that makes sense for the connection you're setting up.
   3. **Authentication Name:** Your Telnyx SIP account username
   4. **Authentication password:** Your Telnyx SIP account password
   5. **Username:** Your Telnyx SIP account username
   6. **Display name:** Your Telnyx SIP account username
   7. **Domain:** *sip.telnyx.com*
   8. **Proxy server address:** *sip.telnyx.com*
   9. **Proxy server port:** If you are using UDP transport, use port *5060*. If you are using TLS transport, use port *5061.*
   10. **Registration server:** *sip.telnyx.com*
   11. **Registration server port:** If you are using UDP transport, use port *5060*. If you are using TLS transport, use port *5061.*
   12. **Registration refresh time:** 300
   13. **STUN enabled:** No
   14. **STUN server address:** (Leave Empty)
   15. **Outbound proxy mode**: Always
   16. **Outbound server address:** *sip.telnyx.com*
   17. **Outbound proxy port:** If you are using UDP or TCP transport, use port *5060*. If you are using TLS transport, use port *5061.*
   18. **Select Network Protocol:** By default, *UDP* is selected. If you enabled TLS and your account is configured to use SRTP encryption as part of your [pre-requisite activities](https://support.telnyx.com/en/articles/5810226-fortifone-fon-570#h_6edc08d8c8) then you should choose *TLS.*

   [![A screenshot of the UDP setup. ](https://downloads.intercomcdn.com/i/o/434941118/a0f0e43513cc6f1778421463/7.png?expires=1781168400&signature=204a007ebeb48e3eca40835a5f907ceb1e21afe577e1e0815c7feda9cf05d124&req=cCMjH81%2FnIBXFb4f3HP0gD08DUi6K9kZyB2PsUou5r03CxzHolsf88jTgC5l%0AIIE%3D%0A)](https://downloads.intercomcdn.com/i/o/434941118/a0f0e43513cc6f1778421463/7.png?expires=1781168400&signature=204a007ebeb48e3eca40835a5f907ceb1e21afe577e1e0815c7feda9cf05d124&req=cCMjH81%2FnIBXFb4f3HP0gD08DUi6K9kZyB2PsUou5r03CxzHolsf88jTgC5l%0AIIE%3D%0A)

   *\*Note that this screenshot shows a UDP setup.*  
   ​
4. Still in the **Telephony** section, click on **Number Assignment** and find the **Handsets** section. Look for the line you just created (It will have the same name as the **Connection Name or Number** field you configured previously.

   1. f**or outgoing calls:** Radio button should be CHECKED
   2. **for incoming calls:** Checkbox should be CHECKED

   [![A510 IP settings. ](https://downloads.intercomcdn.com/i/o/434948490/fa74b1ca939d48a3238e9538/8.png?expires=1781168400&signature=86b31d485a674c4e04131d544b61c24380c5601cac7f6528e42ed24d5b98af94&req=cCMjH812mYhfFb4f3HP0gMKIl1YB5HbvmZmkwaRk%2FGm8BF8GtjMddRbdiUVM%0AWbE%3D%0A)](https://downloads.intercomcdn.com/i/o/434948490/fa74b1ca939d48a3238e9538/8.png?expires=1781168400&signature=86b31d485a674c4e04131d544b61c24380c5601cac7f6528e42ed24d5b98af94&req=cCMjH812mYhfFb4f3HP0gMKIl1YB5HbvmZmkwaRk%2FGm8BF8GtjMddRbdiUVM%0AWbE%3D%0A)

That's it! You've finished configuring your Gigaset A510 IP profile, and can now start testing calls!
