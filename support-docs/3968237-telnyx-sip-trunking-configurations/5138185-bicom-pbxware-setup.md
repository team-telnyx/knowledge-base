[Bicom Systems](https://www.bicomsystems.com/) is a software suite developed by Bicom Systems, from essentials like PBXware to unified communications apps like gloCOM & gloCOM GO. It is everything you need to communicate, collaborate and connect.

Enjoy such features as:

* [PBXware](https://www.bicomsystems.com/products/pbxware/): Open standards turnkey telephony platform
* [SERVERware](https://www.bicomsystems.com/products/serverware/): Server Virtualization Platform
* [sipPROT](https://www.bicomsystems.com/products/sipprot/): SIP Protection Software
* [gloCOM](https://www.bicomsystems.com/products/glocom/): Unified Communication software
* [gloCOM GO](https://www.bicomsystems.com/products/glocom-go/): Unified Communication mobile app
* sipMON: Network packet sniffer for SIP and RTP VoIP protocol

The SMS feature on Bicom PBXware allows users to select Telnyxas a provider in their configuration so that messaging service is fully utilized.
