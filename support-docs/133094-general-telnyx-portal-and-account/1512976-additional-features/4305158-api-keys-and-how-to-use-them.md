# API Keys and How to Use Them

In this article we will explain API keys and how to use them with both API v2 and API v1.

Written by Alex Conroy

January 6, 2026

Table of contents

To use Telnyx v2 API endpoints, you will need an API key. For our API v1 endpoints, you will need an API Token.

This article will explain how to get your API Key for API v2 or API Token for API v1.

Telnyx uses API Keys or Tokens to authenticate API requests from our customers.

# **Step by Step guide API v2 Key**

* Log in to <https://portal.telnyx.com/>
* Click on the Account Settings option in the Account Icon on the top-right corner.
* Then click [API Keys](https://portal.telnyx.com/#/api-keys).

Click Create API Key on the top right hand corner to create an API v2 Key.

This key is what you will use as the bearer token in your API requests.

* If you lose it, you can always go back to this section again to get it or create a new one.
* You have the option to set an Expiration date for your key, or temporarily disable any given API Key by just toggling the option.
* You can also associate up to 10 tags per API Key.

## **Step by Step guide API v1 Token**

* Log in to <https://portal.telnyx.com/>
* Click on the Account Settings dropdown section on the left-hand side.
* Then click [API Keys](https://portal.telnyx.com/#/api-keys).
* Inside this page, click the "[API V1 Tokens](https://portal.telnyx.com/#/app/api-tokens)" button on the top right-hand side.

[![](https://downloads.intercomcdn.com/i/o/ltcafuzd/1312354022/70e9bab6291412db428431893b20/Screenshot+from+2024-12-26+14-25-32.png?expires=1781168400&signature=c4e2c971a11aedb12ab61a9a375e78a94489b69af6b3db0914d43046f264ff43&req=dSMmFMp7mYFdW%2FMW1HO4zYtfU%2Ffn%2F7X1d2aUssX1rFU650HBwxIRbhtin05M%0Asvn%2BG6jrtQiPBz6DhPQ%3D%0A)](https://downloads.intercomcdn.com/i/o/ltcafuzd/1312354022/70e9bab6291412db428431893b20/Screenshot+from+2024-12-26+14-25-32.png?expires=1781168400&signature=c4e2c971a11aedb12ab61a9a375e78a94489b69af6b3db0914d43046f264ff43&req=dSMmFMp7mYFdW%2FMW1HO4zYtfU%2Ffn%2F7X1d2aUssX1rFU650HBwxIRbhtin05M%0Asvn%2BG6jrtQiPBz6DhPQ%3D%0A)

* Click Create API Token.

[![](https://downloads.intercomcdn.com/i/o/ltcafuzd/1312354729/097333a79c7dad8c65521e2f632f/Screenshot+from+2024-12-26+14-26-20.png?expires=1781168400&signature=46f0708de6e0fbe0530d317cb94077d5b5b27368595c515d000772eec87a4eca&req=dSMmFMp7mYZdUPMW1HO4zYHOpx7TIuNQbJEg%2BfGSJliERnqpxNgm6wlPJ%2FbG%0Abi8Id3Gas7QTjdlItWQ%3D%0A)](https://downloads.intercomcdn.com/i/o/ltcafuzd/1312354729/097333a79c7dad8c65521e2f632f/Screenshot+from+2024-12-26+14-26-20.png?expires=1781168400&signature=46f0708de6e0fbe0530d317cb94077d5b5b27368595c515d000772eec87a4eca&req=dSMmFMp7mYZdUPMW1HO4zYHOpx7TIuNQbJEg%2BfGSJliERnqpxNgm6wlPJ%2FbG%0Abi8Id3Gas7QTjdlItWQ%3D%0A)

* We will ask you to give it a name, you can name it whatever you want.
* You will see a section on the right-hand side where you can click Copy Token.
* If you lose it you can always go back to this section again to get it or create a new one.

  + **NOTE**: The API Token will only be visible at the time of creation, so ensure it is securely stored in your application's environment variables.

[![](https://downloads.intercomcdn.com/i/o/ltcafuzd/1917269130/967be5f5c223e712e7830143e3f2/image.png?expires=1781168400&signature=3f5da3732571988d2a075b785f6f4e3b9f83c97d10f0bb03f272f10bbac81d61&req=dSkmEct4lIBcWfMW1HO4zf1SASj4qFqkbVqJcSmVlg%2ByykhgO34iJSSV6bKP%0AL4kRqa3xBjBX2qspgQE%3D%0A)](https://downloads.intercomcdn.com/i/o/ltcafuzd/1917269130/967be5f5c223e712e7830143e3f2/image.png?expires=1781168400&signature=3f5da3732571988d2a075b785f6f4e3b9f83c97d10f0bb03f272f10bbac81d61&req=dSkmEct4lIBcWfMW1HO4zf1SASj4qFqkbVqJcSmVlg%2ByykhgO34iJSSV6bKP%0AL4kRqa3xBjBX2qspgQE%3D%0A)

In your API request, please include two headers called:

* **x-api-user**: <your account email>
* **x-api-token**:<your account token> when making the API V1 request.

You can find more details on API v1 Tokens in our developer's docs [here](https://developers.telnyx.com/api) and our API v2 Key [here](https://developers.telnyx.com/api)
