# What is my SIP Account Connection password?

When you add a new connection in the Telnyx Mission Control portal you will be able to input a username and password. See Telnyx guidance and requirements.




## What is my SIP Account Connection password?

You will be able to create your own SIP password via the Telnyx Mission Control portal. When creating a SIP connection, specify the authentication types as **credentials**. You will be generated a random username and password but can change it. We recommend using a random password generator for additional security.

## Where to find your SIP username and password

Your SIP credentials are set at the SIP connection level in the Telnyx Portal. To find them:

1. Log in to the [Telnyx Portal](https://portal.telnyx.com)
2. Navigate to **[Voice](https://portal.telnyx.com/#/voice/connections)** [→ **SIP Trunking**](https://portal.telnyx.com/#/voice/connections)
3. Find the SIP connection and click the **pencil (edit) icon**
4. Open the **Authentication and routing** tab
5. Your username and password are displayed here, you can view, copy or update them at any time
