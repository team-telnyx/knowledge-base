# Italy Number Porting

Here you will find a detailed list of requirements for Italy number portability. See Telnyx guidance and requirements.




## **Local / National Numbers in Italy**

1. LOA (Local address required)
2. Local TAX / VAT ID or company registration number
3. Migration code
4. Latest Invoice
5. A copy of the Passport / ID of the Authorized Person
6. Fiscal code of the Authorized Person (It is an alphanumeric code of 16 characters)
7. Proof of local address

   *There must be a local address in Italian territory and a legal presence (with a valid fiscal code) to port in Italy.*

## **Toll-free Numbers in Italy**

1. LOA (Local address required)
2. Local TAX / VAT ID or company registration number
3. Latest Invoice
4. A copy of the Passport / ID of the Authorized Person
5. Proof of local address

Download LOA **[here](https://assets.ctfassets.net/taysl255dolk/45LOLnr1ZO8PfWfHpAID9z/cf24bfaa49a0fc3d04900d5c0f9dfac5/LoA_TELNYX_Italy.pdf)**

**PLEASE NOTE**

Once the losing carrier has given confirmation for porting, the porting request can be canceled or postponed :

* For Standard ports, at the latest 5 working days before the port date. After that period, the port will go ahead without possibility of fallback.
* For Mixed Operator/Complex ports, at the latest 7 working days before the port date. After that period, the port will go ahead without possibility of fallback.

Outage during porting may occur.
