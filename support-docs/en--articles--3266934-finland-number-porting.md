# Finland Number Porting

Here you will find all of the requirements for Finland number portability. See Telnyx guidance and requirements.




## **Finland Local/ National Numbers**

1. LOA
2. VAT/TAX ID or social security number
3. Latest Invoice

## **Finland Toll-Free Numbers**

1. LOA
2. VAT/TAX ID or social security number
3. Attorney's authorization for representative (in case number belongs to a company)
4. Latest Invoice

Download POA **[here](https://assets.ctfassets.net/taysl255dolk/BjAY6YlvDP8UHiRtMAtSP/009510c32ea7832407ab6c525f69478a/FINLAND-TELNYX.pdf)**

**Most common rejections for portability**

* Wrong end-user on document

* Signature not readable/valid on the LOA
