# Guatemala DID Requirements

Requirements to acquire Guatemala numbers. See Telnyx guidance and requirements Learn more about Guatemala DID Requirements with Telnyx.




## **DID Number Requirements for Guatemala**

In order to purchase a Guatemala number you will need to provide the following:

## **Local Numbers in Guatemala**

For **business identity** verification:

\* Name, last name of an authorized representative

\* Company Name

\* Contact phone number

\* ID/Passport of authorized representative

\* Local Company Registration Certificate

\* NIT (Tax ID)

\* LOI (Provided by NumberOps)

For **address** verification:

\* Address in Guatemala (street, building number, postal code, city, and country)

\* Proof of address (dated within 3 months)

Please note that once the documentation is received it will take approximately 72 hours to validate the information and activate the number for use.
