# Billing: Decimal Values Considered

How many decimal values does Telnyx consider when billing? See Telnyx guidance and requirements Learn more about Billing: Decimal Values Considered with Telnyx.




## **How many decimal values do we consider for Billing?**

We consider 4 decimal points for billing. For instance our SMS rate is $0.0025 USD
The same goes for our call rates, they are considered up to 4 decimal points.
