# Access Control List

The Access Control List has been deprecated and is no longer active. See Telnyx guidance and requirements.




## Access Control List

The [Access Control List](https://portal.telnyx.com/#/app/allowed-ips/ip-addresses) has been deprecated and is no longer active. No users can add or modify any IPs to the ACL at this moment.

This is regardless of the account level.
