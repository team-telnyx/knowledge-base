# Austria Number Porting

Here you will find detailed requirements for Austria number portability. See Telnyx guidance and requirements.




## **Local and National Numbers in Austria**

1. LOA (Local address required)
2. Account Number
3. ID / Passport copy
4. Company Registration certificate
5. Latest Invoice
6. Proof of address

## **Toll-Free Numbers Available in Austria**

1. LOA
2. Current underlying carrier’s name
3. Porting history (if the number(s) were ported before)
4. Account Number
5. Latest Invoice
