# Switzerland Number Porting

Here you will find the requirements for Switzerland number portability. See Telnyx guidance and requirements.




## Porting Local / National Numbers in Switzerland

1. LOA (porting wish date must be mentioned, the signature must be a wet signature) - if you are porting numbers under a business, the Authorized person must have full authority to act on behalf of that business.
2. Latest Invoice
3. VAT / TAX ID
4. Proof of address dated within 3 Months of request (Latest invoice/Utility Bill/Insurance)

## Porting Toll-free Numbers

1. LOA (porting wish date must be mentioned)
2. Latest Invoice
3. Ownership proof from BAKOM (with ref number)

**Please note**, a single number belonging to a DDI Range, cannot be ported out separately. In order for a DDI Range to be ported, it must include at least 10 successive Numbers or a multiple of it. The first number of range to end with 0 and the last number of range to end with 9. These details are available with the current provider.
