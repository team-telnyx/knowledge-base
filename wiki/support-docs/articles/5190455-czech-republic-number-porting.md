# Czech Republic Number Porting

Here you will find a detailed list of requirements for Czech Republic number portability. See Telnyx guidance and requirements.




## **For Local / National / Toll-Free number Types in Czech Republic**

1. LoA (Local Service address)

2. OKU ( Migration code)

3. Latest Invoice

4. VAT / TAX ID

5. Proof of address

Contact [porting@telnyx.com](mailto:porting@telnyx.com) for the LoA template for porting in the Czech Republic.

Requesting and completing the Czech Republic authorization letter is essential for smooth number porting. Delve deeper into our [Czech Republic number pricing](https://telnyx.com/pricing/numbers/cz).
