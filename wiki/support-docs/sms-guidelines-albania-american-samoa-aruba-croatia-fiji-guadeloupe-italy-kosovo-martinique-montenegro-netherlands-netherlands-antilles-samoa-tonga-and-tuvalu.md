# SMS Guidelines: Albania, American Samoa, Aruba, Croatia, Fiji, Guadeloupe, Italy, Kosovo, Martinique, Montenegro, Netherlands, Netherlands Antilles, Samoa, Tonga, and Tuvalu

This page consolidates Telnyx SMS guidelines for fifteen destinations across Europe, the Caribbean, the Pacific, and the Balkans. Each destination supports alphanumeric Sender IDs without registration and has no content restrictions, though all traffic must comply with the Telnyx Acceptable Use Policy for Messaging.

## Overview

Telnyx supports outbound SMS to the destinations listed on this page under a consistent set of rules: alphanumeric Sender IDs are supported and maintained without registration, and there are no destination-specific content restrictions. All messaging traffic must still comply with the [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md).

The table below summarizes the Mobile Country Code (MCC) and international dial code for each destination covered here.

| Destination | MCC | Dial Code |
| --- | --- | --- |
| Albania | 276 | 355 |
| American Samoa | 311 - 544 | 684 |
| Aruba | 363 | 297 |
| Croatia | 219 | 385 |
| Fiji | 542 | 679 |
| Guadeloupe | 340 | 590 |
| Italy | 222 | 39 |
| Kosovo | 221 | 383 |
| Martinique | 340 | 596 |
| Montenegro | 297 | 382 |
| Netherlands | 204 | 31 |
| Netherlands Antilles | 362 | 599 |
| Samoa | 549 | 685 |
| Tonga | 539 | 676 |
| Tuvalu | 553 | 688 |

## Sender ID and Content Rules

For every destination on this page, the following rules apply:

- **Alphanumeric Sender IDs** are supported and will be maintained. No Sender ID registration is required.
- **Content restrictions:** there are no destination-specific restrictions on message content.
- **Compliance:** all messages must adhere to the [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md).
