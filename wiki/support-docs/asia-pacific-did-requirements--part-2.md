# Asia-Pacific DID Requirements

*Part 2 of 3 — see also: [Part 1](asia-pacific-did-requirements--part-1.md), [Part 3](asia-pacific-did-requirements--part-3.md)*

Requirements for purchasing Telnyx DID numbers across Asia-Pacific countries, covering identity, business, and address verification documents needed for local, national, toll-free, mobile, and shared cost number types.

## Malaysia

### Local Numbers

Business use is required; private use is not allowed.

**Business identity verification:**
- Name, last name of an authorized representative
- Contact phone number
- Company name
- Passport or ID copy of an authorized representative

**Address verification:**
- Address in Malaysia (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

### National Numbers

Business use is required; private use is not allowed.

**Business identity verification:**
- Name, last name of an authorized representative
- Contact phone number
- Company name
- Passport or ID copy of an authorized representative
- Malaysian company registration certificate
- Signed LOI (dated within 1 month)

**Address verification:**
- Address in Malaysia (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

### Toll-Free Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number

**Business identity verification:**
- Name, last name of an authorized representative
- Contact phone number
- Company name

**Address verification:**
- Address in Malaysia (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

### Mobile Numbers

Business use is required; private use is not allowed.

**Business identity verification:**
- Name, last name of an authorized representative
- Contact phone number
- Passport or ID copy of an authorized representative
- Company name
- Company registration certificate
- Signed LOI (dated within 1 month)

**Address verification:**
- Worldwide address (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

Documentation validation and number activation takes approximately 72 hours.
