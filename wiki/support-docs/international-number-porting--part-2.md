# International Number Porting

*Part 2 of 2 — see also: [Part 1](international-number-porting--part-1.md)*

A guide to porting phone numbers to Telnyx across Australia, New Zealand, Turkey, and Singapore, covering portable number types, port categories, expected timeframes, document requirements, and the porting process for each country.

## Porting Process

The general workflow is the same across all countries:

1. Gather all required documents based on the country and account type
2. Submit a port request through [Mission Control](https://portal.telnyx.com)
3. Select the correct port type or category (e.g., CAT A/C/Special for Australia, DEL/DID for Singapore)
4. Upload the LOA and all supporting documents
5. Telnyx submits the request to the losing carrier
6. Receive FOC confirmation with the activation date
7. Numbers activate on the scheduled FOC date

For Australian mobile ports, an additional mobile verification step is required before submission (see the [Mobile Verification Requirement](#mobile-verification-requirement) section above).

## Contact and Support

For questions about number porting in any of these countries, contact [porting@telnyx.com](mailto:porting@telnyx.com).

**Porting Hours:**

- **Australia** — Standard time 8 AM to 12 PM local
- **New Zealand** — Monday to Friday, 8 AM or 12 PM time slots
