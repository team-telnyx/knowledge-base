# Africa and Caribbean SMS Guidelines

Consolidated Telnyx SMS sending guidelines for Benin, Cameroon, Congo, Democratic Republic of the Congo, Cote d'Ivoire, Equatorial Guinea, Ghana, Guinea, Guinea-Bissau, Haiti, Liberia, Rwanda, Uganda, Zambia, and Zimbabwe, including MCC, dial code, and Alphanumeric Sender ID registration requirements per network.

## Overview

This page consolidates Telnyx SMS sending guidelines for a set of African and Caribbean destinations. Across most of these countries, Alphanumeric Sender IDs are supported, but registration is required for delivery to specific mobile networks (most commonly MTN). Without registration on those networks, Alpha Senders are typically overwritten to a Generic Alpha Sender ID or fail to deliver. Generic Alpha Sender IDs are not recommended, and Alpha Senders should be directly related to the message content. All senders must comply with the [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md). For Alpha Sender ID registration, contact [alpha_sender_id@telnyx.com](mailto:alpha_sender_id@telnyx.com).

## Country Guidelines

### Benin
- **MCC:** 616
- **Dial Code:** +229
- Alphanumeric Sender IDs are supported.
- For Network MTN (61603), Alphanumeric Sender IDs are only supported with registration. Without registration, Alpha Senders will be overwritten to Generic Alpha Sender IDs or will NOT deliver.
- Generic Alpha Sender IDs are not recommended; Alpha Senders should be directly related to the message content.

### Democratic Republic of the Congo

- For Network Vodacom (63001), Alphanumeric Sender IDs are only supported with registration. Outside of this network, Alphanumeric Sender IDs can be replaced by a Generic Alpha Sender ID or a random [Short Code](https://telnyx.com/products/sms-short-code).
