# European DID Number Requirements

*Part 2 of 2 — see also: [Part 1](european-did-number-requirements--part-1.md)*

Regulatory requirements for purchasing Telnyx DID numbers across several European countries, including identity and address verification documents needed for local, national, and toll-free number types.

## Key Patterns Across Countries

- **Local numbers** generally require an address matching the DID area code and proof of address dated within the last 3 months.
- **Toll-free and national numbers** typically accept a worldwide address without area code matching requirements.
- **Business use only** restrictions apply to local numbers in Montenegro and Slovenia.
- **Physical presence** in the country at the time of purchase is required for Italy and Greece.
- Documents must be submitted in .pdf format (explicitly stated for Italy; recommended as best practice elsewhere).
