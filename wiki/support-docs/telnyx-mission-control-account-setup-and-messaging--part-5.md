# Telnyx Mission Control Account Setup and Messaging

*Part 5 of 5 — see also: [Part 1](telnyx-mission-control-account-setup-and-messaging--part-1.md), [Part 2](telnyx-mission-control-account-setup-and-messaging--part-2.md), [Part 3](telnyx-mission-control-account-setup-and-messaging--part-3.md), [Part 4](telnyx-mission-control-account-setup-and-messaging--part-4.md)*

This page covers how to sign up for a Telnyx Mission Control account, configure it for voice and messaging, send SMS and Alphanumeric SMS via Postman using API v1 and v2, understand global Alphanumeric Sender ID capabilities by country, and access useful Mission Control resources.

## Useful Mission Control Resources

Available on the bottom left-hand side of your account, you will see four useful resources that can be quickly accessed:

- **Support** — [https://support.telnyx.com/](https://support.telnyx.com/en/) — Access the Telnyx knowledge base.
- **API Docs** — [https://developers.telnyx.com/](https://developers.telnyx.com/) — Developer documentation for Telnyx APIs and SDKs.
- **Release Notes** — [https://telnyx.com/release-notes](https://telnyx.com/release-notes) — Latest news on recently and historically released features.
- **System Status** — [https://status.telnyx.com/](https://status.telnyx.com/) — Subscribe to keep up to date for any incidents.

Another useful resource is the [Telnyx resource center](https://telnyx.com/resources), where you can find industry-discussed topics along with tutorials and demos of Telnyx products in use.
