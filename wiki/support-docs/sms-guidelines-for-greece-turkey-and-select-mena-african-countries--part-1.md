# SMS Guidelines for Greece, Turkey, and Select MENA & African Countries

*Part 1 of 2 — see also: [Part 2](sms-guidelines-for-greece-turkey-and-select-mena-african-countries--part-2.md)*

Consolidated Telnyx SMS sending guidelines for Greece, Turkey, and a range of Middle East, North Africa, and African destinations. Each country requires Alphanumeric Sender ID registration, with country-specific rules on content restrictions, time windows, and registration documentation.

## Overview

Telnyx requires Alphanumeric Sender ID registration for SMS traffic to Greece, Turkey, and the MENA/African destinations covered on this page. In most of these destinations, messages sent from unregistered Sender IDs will be rejected by the terminating operator. The registration process, supporting documents, and content rules vary slightly by country, and are detailed in the sections below.

## Greece

- **MCC:** 202
- **Dial Code:** 30
- Alphanumeric Sender ID registration is required. All messages from unregistered Sender IDs will be rejected.
- Consent (proof of opt-in) should be obtained before sending any communications, including marketing SMS.
- Traffic should include clear opt-out options.
- See [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md) for full messaging rules.

## Turkey

- **MCC:** 286
- **Dial Code:** 90
- Alphanumeric Sender IDs are supported with registration. Alphanumeric Sender ID registration is required.
- A 4-character code beginning with the letter "B" will be appended to the end of the message content by the terminating operator, in line with Information and Communication Technologies Authority (BTK) guidelines.
- Gambling traffic is not allowed towards Turkey.
- See [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md) for full messaging rules.

## United Arab Emirates

- **MCC:** 424
- **Dial Code:** 971
- Alphanumeric Sender IDs are supported with registration. Alphanumeric Sender ID registration is required.
- For promotional traffic, the suffix "AD" must be added to the Alphanumeric Sender for traffic distinction.
- Promotional traffic is not allowed between 09:00 pm and 07:00 local time. All traffic submitted during this window will be queued, and delivery will be attempted outside the restricted period.
- Religious, gambling, political, and adult traffic is prohibited.
- The use of generic Alpha Sender IDs is not recommended. Alpha Senders should be directly related to the message content.
- See [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md) for full messaging rules.
