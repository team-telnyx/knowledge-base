# SMS Guidelines for Select Destinations

This page consolidates Telnyx SMS guidelines for 15 destinations, including MCC, dial code, sender ID support, and any content restrictions. Most destinations support alphanumeric sender IDs without registration and have no content restrictions, with a few exceptions for adult, political, religious, or gambling content.

## Overview

Telnyx provides SMS messaging services to a wide range of destinations worldwide. The following table summarizes key information for each destination, including the Mobile Country Code (MCC), dial code, sender ID support, and any applicable content restrictions.

| Destination | MCC | Dial Code | Sender ID Support | Content Restrictions |
|---|---|---|---|---|
| Antigua y Barbuda | 344 | 1268 | Alphanumeric Sender IDs supported, no registration required | None |
| Bahrain | 426 | 973 | Alphanumeric Sender IDs supported, no registration required | Adult, political, and religious content blocked by local operators |
| Barbados | 342 | 1246 | Alphanumeric Sender IDs supported, no registration required | None |
| Bermuda | 350 | 1441 | Alphanumeric Sender IDs supported, no registration required | None |
| Cayman Islands | 346 | 1345 | Alphanumeric Sender IDs supported, no registration required | None |
| Falkland Islands | 750 | 500 | Alphanumeric Sender IDs supported, no registration required | None |
| Gibraltar | 266 | 350 | Alphanumeric Sender IDs supported, no registration required | None |
| Grenada | 352 | 1473 | Alphanumeric Sender IDs supported, no registration required | None |
| Israel | 425 | 972 | Alphanumeric Sender IDs supported, no registration required | Religious, gambling, political, or adult traffic prohibited |
| New Caledonia | 546 | 687 | Alphanumeric Sender IDs supported, no registration required | None |
| Norfolk Island | 505 | 672 | Alphanumeric Sender IDs supported, no registration required | None |
| Saint Kitts & Nevis | 356 | 1869 | Alphanumeric Sender IDs supported, no registration required | None |
| Saint Lucia | 358 | 1758 | Alphanumeric Sender IDs supported, no registration required | None |
| Saint Vincent and the Grenadines | 360 | 1784 | Alphanumeric Sender IDs supported, no registration required | None |
| Virgin Islands (British) | 348 | 1340 | Alphanumeric Sender IDs supported, no registration required | None |

## Sender ID and Registration

Across all 15 destinations, alphanumeric sender IDs are supported and will be maintained. None of these destinations require sender ID registration.

## Content Restrictions

Most destinations have no content restrictions. The following destinations have specific content limitations:

- **Bahrain**: Adult, political, and religious content will be blocked by local operators.
- **Israel**: Religious, gambling, political, or adult traffic is prohibited.

## Acceptable Use Policy

All SMS messaging must comply with the Telnyx [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md). Always refer to this policy when sending messages to any destination.
