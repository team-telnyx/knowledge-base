# Middle East and Africa SMS Guidelines

Consolidated Telnyx SMS sending guidelines for Afghanistan, Algeria, Bahrain, Greece, Iraq, Israel, Jordan, Kuwait, Lebanon, Libya, Malawi, Pakistan, Qatar, Syria, and Tunisia, including MCC, dial codes, Alphanumeric Sender ID registration requirements, content restrictions, and country-specific rules.

## Overview

This page consolidates Telnyx SMS sending guidelines for the following countries: Afghanistan, Algeria, Bahrain, Greece, Iraq, Israel, Jordan, Kuwait, Lebanon, Libya, Malawi, Pakistan, Qatar, Syria, and Tunisia. Each country entry lists the Mobile Country Code (MCC), international dial code, and the rules governing Alphanumeric Sender ID usage, content restrictions, and registration requirements.

## Countries Requiring Alphanumeric Sender ID Registration

For the following countries, Alphanumeric Sender ID registration is required and all messages from unregistered Sender IDs will be rejected: Afghanistan, Algeria, Greece, Iraq, Jordan, Kuwait, Lebanon, Libya, Malawi, Pakistan, Qatar, Syria, and Tunisia.

### Registration Submission

To register an Alphanumeric Sender ID, send the following details along with a copy of your Business Registration to [alpha_sender_id@telnyx.com](mailto:alpha_sender_id@telnyx.com):

1. SenderID to be registered
2. Message/Content type
3. Message/Content example
4. Company name (and Brand name if different)
5. Website of brand or company
6. Company Country of origin
7. Expected volumes per month
8. Email linked to your Telnyx account

Companies must have a valid business case for the requested Alphanumeric Sender ID. If the relationship between your company/brand and the requested Alphanumeric Sender ID is not clear, please provide additional supporting documentation detailing your business case.

### Country-Specific Notes for Registration-Required Countries

- **Jordan:** Promotional traffic can only be sent between 7 A.M. and 9 P.M. local time. Alphanumeric Senders used for promotional traffic must include the prefix "ADV".
- **Pakistan:** Gambling related traffic is not permitted.
- **Qatar:** The use of generic Alpha Sender IDs is not recommended. Alpha Senders should be directly related to the message content. Religious, political, or adult traffic is prohibited.
- **Tunisia:** The use of generic Alpha Sender IDs is not recommended. Alpha Senders should be directly related to the message content.

## Countries Not Requiring Sender ID Registration

### Bahrain

Alphanumeric Sender IDs are supported and will be maintained; no registration is required. Adult, political, and religious content will be blocked by local operators.

### Israel

Alphanumeric Sender IDs are supported and will be maintained; no registration is required. Religious, gambling, political, or adult traffic is prohibited.

## General Recommendations

For all countries covered on this page, the following best practices apply:

- Consent (Proof of Opt-in) should be obtained before sending any communications, including Marketing SMS.
- Traffic should include clear Opt-Out options.
- Always refer to the [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md).
- For more information on Alpha Sender ID registration, contact [alpha_sender_id@telnyx.com](mailto:alpha_sender_id@telnyx.com).
