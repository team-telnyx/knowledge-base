# Pacific Islands: SMS Guidelines

Consolidated Telnyx SMS delivery rules for American Samoa, Cook Islands, French Polynesia, Guam, Palau, Samoa, Tonga, Tuvalu, and Kiribati. Includes MCCs, dial codes, Sender ID support, and any noted restrictions. Always ensure campaigns comply with Telnyx’s Acceptable Use Policy for Messaging.

## Overview
- Destinations covered: American Samoa, Cook Islands, French Polynesia, Guam, Palau, Samoa, Tonga, Tuvalu, Kiribati.
- Sender ID support: Alphanumeric Sender IDs are supported and maintained without registration in all listed destinations except Guam.
- Guam exception: Alphanumeric Sender IDs are not allowed; only Long Code traffic is permitted.
- Content restrictions: No specific content restrictions are noted for these destinations; standard Telnyx policies apply. See Telnyx’s Acceptable Use Policy for Messaging: https://support.telnyx.com/en/articles/1310359-acceptable-use-policy-for-messaging.
- MCC = Mobile Country Code; “Dial Code” as provided by Telnyx sources for each destination.

## American Samoa
- MCC: 311 - 544
- Dial Code: 684
- Sender ID: Alphanumeric supported and maintained; no registration required.
- Content restrictions: None noted.

## Cook Islands
- MCC: 682
- Dial Code: 548
- Sender ID: Alphanumeric supported and maintained; no registration required.
- Content restrictions: None noted.

## French Polynesia
- MCC: 547
- Dial Code: 689
- Sender ID: Alphanumeric supported and maintained; no registration required.
- Content restrictions: None noted.

## Guam
- MCC: 310
- Dial Code: 1671
- Sender ID: Alphanumeric not allowed/supported.
- Permitted traffic type: Long Code only.

## Palau
- MCC: 552
- Dial Code: 680
- Sender ID: Alphanumeric supported and maintained; no registration required.
- Content restrictions: None noted.

## Samoa
- MCC: 549
- Dial Code: 685
- Sender ID: Alphanumeric supported and maintained; no registration required.
- Content restrictions: None noted.

## Tonga
- MCC: 539
- Dial Code: 676
- Sender ID: Alphanumeric supported and maintained; no registration required.
- Content restrictions: None noted.

## Tuvalu
- MCC: 553
- Dial Code: 688
- Sender ID: Alphanumeric supported and maintained; no registration required.
- Content restrictions: None noted.

## Kiribati
- MCC: 545
- Dial Code: 686
- Sender ID: Alphanumeric supported and maintained; no registration required.
- Content restrictions: None noted.
