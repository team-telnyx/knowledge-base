# SMS Guidelines: Open Sender ID Destinations - Estonia to Slovakia

This page consolidates Telnyx SMS guidelines for destinations where Alphanumeric Sender IDs are supported without registration and where there are no content restrictions. It covers country-specific identifiers (MCC and dial code) for each destination, including several European countries, Caribbean nations, and island territories.

## Overview

Telnyx supports Alphanumeric Sender IDs across a broad set of destinations without requiring sender registration. For each destination listed on this page, the following conditions apply:

- **Alphanumeric Sender IDs** are supported and will be maintained.
- **No registration** is required to use an Alphanumeric Sender ID.
- **No content restrictions** apply specifically to the destination.

All messaging traffic must still comply with the [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md).

## Common Sender ID and Content Rules

Across every destination on this page, the same operational rules apply:

- **Sender ID type:** Alphanumeric Sender IDs are supported and maintained by Telnyx.
- **Registration:** None required. Customers can send using an Alphanumeric Sender ID without prior approval.
- **Content restrictions:** None at the destination level. Carriers in these countries do not impose additional content filtering beyond what is generally applied.
- **Compliance:** All messages must continue to follow the [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md), which governs prohibited content, messaging practices, and acceptable use across the Telnyx network.

## Reference Identifiers

The following reference identifiers are useful when configuring messaging traffic or troubleshooting delivery:

- **MCC (Mobile Country Code):** A three-digit code that uniquely identifies the country of a mobile subscriber. It is used in combination with the Mobile Network Code (MNC) to identify the carrier.
- **Dial Code:** The international dialing prefix used to reach the destination from abroad.
