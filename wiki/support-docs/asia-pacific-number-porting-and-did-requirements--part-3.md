# Asia-Pacific Number Porting and DID Requirements

*Part 3 of 4 — see also: [Part 1](asia-pacific-number-porting-and-did-requirements--part-1.md), [Part 2](asia-pacific-number-porting-and-did-requirements--part-2.md), [Part 4](asia-pacific-number-porting-and-did-requirements--part-4.md)*

Consolidated reference for Telnyx number porting and DID acquisition across APAC and Finland, covering portable number types, expected timeframes, port categories, document requirements, LOA downloads, and country-specific rules for Australia, New Zealand, Singapore, China, Hong Kong, Vietnam, Malaysia, Thailand, Indonesia, the Philippines, and Finland.

## Malaysia DID Requirements

Business use is required for Malaysia local, national, and mobile numbers; private use is not allowed. Once documentation is received, validation and activation take approximately 72 hours.

### Local Numbers in Malaysia

**Business identity verification:**

- Name and last name of an authorized representative
- Contact phone number
- Company name
- Passport or ID copy of an authorized representative

**Address verification:**

- Address in Malaysia (street, building number, postal code, city, country)
- Proof of address (dated within 3 months)

### National Numbers in Malaysia

**Business identity verification:**

- Name and last name of an authorized representative
- Contact phone number
- Company name
- Passport or ID copy of an authorized representative
- Malaysian company registration certificate
- Signed LOI (dated within 1 month)

**Address verification:**

- Address in Malaysia (street, building number, postal code, city, country)
- Proof of address (dated within 3 months)

### Toll-Free Numbers in Malaysia

**Personal identity verification:**

- Name, last name
- Contact phone number

**Business identity verification:**

- Name and last name of an authorized representative
- Contact phone number
- Company name

**Address verification:**

- Address in Malaysia (street, building number, postal code, city, country)
- Proof of address (dated within 3 months)

### Mobile Numbers in Malaysia

**Business identity verification:**

- Name and last name of an authorized representative
- Contact phone number
- Passport or ID copy of an authorized representative
- Company name
- Company registration certificate
- Signed LOI (dated within 1 month)

**Address verification:**

- Worldwide address (street, building number, postal code, city, country)
- Proof of address (dated within 3 months)
