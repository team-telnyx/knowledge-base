# European Number Porting Requirements

This page consolidates Telnyx's number porting requirements for European countries, including Belgium, Croatia, Greece, Panama, Norway, Latvia, Luxembourg, Romania, Slovakia, Slovenia, Albania, Czech Republic, Lithuania, and Malta. It lists the documents required for each country (such as LOA, VAT/TAX ID, latest invoice, and proof of address) and provides links to download country-specific Letters of Authorization.

## Overview

Telnyx supports number porting across many European countries. While the core documentation is similar — typically a Letter of Authorization (LoA), a recent invoice from the current carrier, and tax/company identification — each country has specific requirements and a country-specific LoA template. The sections below summarize the requirements per country and link to the relevant LoA download.

## Belgium

For local numbers in Belgium, the area code of the number must match the address registered on file.

- **Local numbers:** LoA (local address required, area code must match the registered address), VAT/TAX ID, latest invoice, proof of local address.
- **National and Toll-Free numbers:** LoA (national address required), VAT/TAX ID, latest invoice, proof of local address.

Download the Belgium LoA from the [Telnyx international LoA template](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

## Croatia

- **Local / National numbers:** LoA, ID/Passport copy, Company Registration certificate, latest invoice.
- **Toll-Free numbers:** LoA, ID/Passport copy or Company Registration certificate, latest invoice.

Download the [Croatia porting form](https://www.dropbox.com/s/1kd2hs03tq8o0bg/Croatia_Porting_Form.pdf?dl=0).

## Greece

For local number types in Greece, the latest invoice must list the numbers being ported.

- **Local numbers:** LoA, Greek TAX/VAT ID or company registration number, ID/Passport copy, Company Registration certificate, latest invoice (numbers must be indicated on the invoice).

Download the [Greece LoA](http://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

## Panama

Although Panama is not in Europe, it is included here for completeness.

- **Local / Toll-Free numbers:** LoA, ID/Passport copy, Company Registration certificate, latest invoice, latest proof of payment.

Download the [Panama porting form](https://www.dropbox.com/s/jw6ki4mjqoqp7y6/Panama_porting_form.pdf?dl=0).

## Norway

A local address is mandatory for porting numbers to or from Norway.

- **Local / National / Toll-Free numbers:** LoA (local address mandatory), latest invoice, local TAX ID/VAT.

Download the [Norway LoA](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

For additional context, see the [Norway Numbers Pricing page](https://telnyx.com/pricing/numbers/no), the [porting timelines article](https://telnyx.com/resources/porting-phone-numbers-take-long), the [Telnyx number porting product page](https://telnyx.com/products/number-porting), the [Porting Policy & Procedure](porting-policy-procedure.md) page, the [Porting Away from Twilio](porting-away-from-twilio.md) guide, the [Porting Error Messages](porting-error-messages.md) troubleshooting page, the [Porting Requirements](porting-requirements.md) page, and the [Best Practices for Contacting Porting Support](best-practices-for-contacting-porting-support.md) page.

## Latvia

- **Local / National numbers:** LoA, latest invoice, ID number of the authorized person, Company Registration number (only if the number belongs to a company).

Download the [Latvia LoA](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

## Luxembourg

- **Local, National, and Toll-Free numbers:** LoA, VAT/TAX ID, local contact phone number, latest invoice.

Download the [Luxembourg LoA](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

## Romania

- **Local and Toll-Free numbers:** LoA, latest invoice, Company Registration certificate, copy of authorized person's ID or passport, VAT/TAX ID.

Download the [Romania LoA](https://assets.ctfassets.net/taysl255dolk/5FZ4qUVt9KGSMsGzbMK6zm/c09622fb44aac104169c67344c25dcf1/Portability_Form_-_Telnyx_-_Romania.pdf).

## Slovakia

- **Local, National, and Toll-Free numbers:** LoA, VAT/TAX ID, latest invoice.

Download the [Slovakia LoA](https://assets.ctfassets.net/taysl255dolk/1od8xuO7Y7WKUrIlXXCM2t/57023f6b1ab4e56954597cfeb5151aa4/Slovakia_telnyx.pdf).

## Slovenia

- **Local / National and Toll-Free numbers:** LoA, VAT/TAX ID, latest invoice with the current provider.

Download the [Slovenia LoA template](https://portal.telnyx.com/downloads/other/Telnyx-LOA.pdf).

## Albania

- **Local / National numbers:** LoA, TAX ID/VAT or Company Registration number, latest invoice, copy of authorized person's ID or passport.

Contact [porting@telnyx.com](mailto:porting@telnyx.com) for the Albania LoA template. See also the [Albania number pricing page](https://telnyx.com/pricing/numbers/al), the [porting timelines article](https://telnyx.com/resources/porting-phone-numbers-take-long), the [Telnyx number porting product page](https://telnyx.com/products/number-porting), the [Porting Policy & Procedure](porting-policy-procedure.md) page, the [Porting Away from Twilio](porting-away-from-twilio.md) guide, the [Porting Error Messages](porting-error-messages.md) troubleshooting page, the [Porting Requirements](porting-requirements.md) page, and the [Best Practices for Contacting Porting Support](best-practices-for-contacting-porting-support.md) page.

## Czech Republic

- **Local / National / Toll-Free numbers:** LoA (local service address), OKU migration code, latest invoice, VAT/TAX ID, proof of address.

Contact [porting@telnyx.com](mailto:porting@telnyx.com) for the Czech Republic LoA template. See also the [Czech Republic number pricing page](https://telnyx.com/pricing/numbers/cz).

## Lithuania

- **Local / National / Toll-Free numbers:** LoA, latest invoice, VAT/TAX ID if the number belongs to a company; otherwise a Personal ID code (asmens kodas) is required.

Download the [Lithuania LoA](https://assets.ctfassets.net/taysl255dolk/d30N9jIww0vlZyFZrovAP/58d1196eba9eb350947708a2de8bc840/Lithuania_Loa_-_Telnyx.pdf). See also the [Lithuania number pricing page](https://telnyx.com/pricing/numbers/lt).

## Malta

- **Local / National numbers:** LoA, VAT/TAX ID, latest invoice with the current carrier, Company Registration certificate, copy of authorized person's ID or passport.

Download the [Malta LoA](https://assets.ctfassets.net/taysl255dolk/4eNcFSEqPgAGcs7H5JsOZ3/b26904cf82b11c3d13f925fbf81972ae/LoA_-_Telnyx_-_NZ-malta.pdf).

For additional context, see the [porting timelines article](https://telnyx.com/resources/porting-phone-numbers-take-long), the [Telnyx number porting product page](https://telnyx.com/products/number-porting), the [Porting Policy & Procedure](porting-policy-procedure.md) page, the [Porting Away from Twilio](porting-away-from-twilio.md) guide, the [Porting Error Messages](porting-error-messages.md) troubleshooting page, the [Porting Requirements](porting-requirements.md) page, and the [Best Practices for Contacting Porting Support](best-practices-for-contacting-porting-support.md) page.
