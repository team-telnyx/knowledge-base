# West and Central Africa: SMS Guidelines

Sender ID rules, registration requirements, content restrictions, and operator‑specific notes for sending SMS to select West and Central African countries via Telnyx. Use this page to confirm whether Alphanumeric Sender IDs are supported and if registration is required, plus how to register and best‑practice compliance tips.

## Scope and quick facts
- Covered destinations: Angola, Cameroon, Central African Republic, Chad, Comoros, Republic of the Congo, Democratic Republic of the Congo, Equatorial Guinea, Gabon, Mali, Mauritania, Niger, Nigeria, São Tomé and Príncipe.
- Alphanumeric Sender IDs are generally supported across these markets; several require prior registration. Unregistered traffic in those markets will be rejected.
- Generic/overly broad alphanumeric Sender IDs are not recommended; the Sender should clearly relate to your brand and message content.
- Always follow Telnyx’s Acceptable Use Policy: https://support.telnyx.com/en/articles/1310359-acceptable-use-policy-for-messaging
- Registration and questions: email alpha_sender_id@telnyx.com

## Alphanumeric Sender ID registration process
Where registration is required, submit the following to alpha_sender_id@telnyx.com along with a copy of your Business Registration:
1) Sender ID to be registered
2) Message/content type
3) Message/content example
4) Company name (and Brand name if different)
5) Website of brand or company
6) Company country of origin
7) Expected monthly volumes
8) Email linked to your Telnyx account

Notes
- You must have a valid business case for the requested Sender ID. If the relationship between your company/brand and the requested Sender is not clear, include supporting documentation.
- Best practices (explicitly called out in several markets below): obtain prior consent/opt‑in before sending (especially for marketing) and include clear opt‑out instructions in your messages.

## Country‑specific rules
### Angola (MCC 631, Dial Code 244)
- Alphanumeric Sender IDs supported and maintained; no registration required.
- No content restrictions noted toward this destination.

### Cameroon (MCC 624, Dial Code 237)
- Alphanumeric Sender IDs supported.
- Network MTN (62401): registration required; without registration, Sender IDs may be overwritten to a generic value or not deliver.
- Generic Alpha not recommended; Sender should directly relate to the message content.

### Central African Republic (MCC 623, Dial Code 236)
- Alphanumeric Sender IDs supported and maintained; no registration required.
- No content restrictions noted toward this destination.

### Chad (MCC 622, Dial Code 235)
- Registration required; messages from unregistered Sender IDs will be rejected.
- Recommendations: obtain opt‑in consent and include clear opt‑out options.

### Comoros (MCC 654, Dial Code 269)
- Registration required; messages from unregistered Sender IDs will be rejected.
- Recommendations: obtain opt‑in consent and include clear opt‑out options.

### Republic of the Congo (Congo‑Brazzaville) (MCC 629, Dial Code 242)
- Alphanumeric Sender IDs supported.
- Network MTN (62910): registration required; without registration, Sender IDs may be overwritten to a generic value or not deliver.
- Generic Alpha not recommended; Sender should directly relate to the message content.

### Democratic Republic of the Congo (DRC) (MCC 243, Dial Code 630)
- Alphanumeric Sender IDs supported.
- Network Vodacom (63001): registration required.
- Outside this network, Alphanumeric Sender IDs can be replaced by a generic Alpha or a random short code. See: https://developers.telnyx.com/docs/messaging/messages/alphanumeric-sender-id and https://telnyx.com/products/sms-short-code

### Equatorial Guinea (MCC 627, Dial Code 240)
- Alphanumeric Sender IDs supported and maintained; no registration required.
- No content restrictions noted toward this destination.

### Gabon (MCC 628, Dial Code 241)
- Registration required; messages from unregistered Sender IDs will be rejected.
- Recommendations: obtain opt‑in consent and include clear opt‑out options.

### Mali (MCC 610, Dial Code 223)
- Alphanumeric Sender IDs supported.
- Local traffic: registration required for Alphanumeric Sender IDs.
- International traffic: no registration required; Alphanumeric Sender IDs supported.

### Mauritania (MCC 609, Dial Code 222)
- Alphanumeric Sender IDs supported and maintained; no registration required.
- Generic Alpha not recommended; Sender should directly relate to the message content.
- No content restrictions noted toward this destination.

### Niger (MCC 614, Dial Code 227)
- Registration required; messages from unregistered Sender IDs will be rejected.
- Recommendations: obtain opt‑in consent and include clear opt‑out options.

### Nigeria (MCC 621, Dial Code 234)
- Registration required; messages from unregistered Sender IDs will be rejected.
- Recommendations: obtain opt‑in consent and include clear opt‑out options.
- Prohibited content: religious, gambling, political, or adult traffic.
- Generic Alpha not recommended; Sender should directly relate to the message content.

### São Tomé and Príncipe (MCC 626, Dial Code 239)
- Alphanumeric Sender IDs supported and maintained; no registration required.
- No content restrictions noted toward this destination.
