# International Number Porting and Ordering — Required Documents

*Part 1 of 3 — see also: [Part 2](international-number-porting-and-ordering-required-documents--part-2.md), [Part 3](international-number-porting-and-ordering-required-documents--part-3.md)*

This page consolidates Telnyx's international number porting and ordering documentation requirements. It covers how to submit port requests via the Telnyx Portal, country-specific porting requirements and LoA templates for countries including Austria, Belgium, Czech Republic, Hungary, Israel, Luxembourg, Netherlands, Norway, Romania, Slovakia, and Slovenia, plus the comprehensive international numbers required documents table, document code definitions, additional requirements, international toll-free local dialling rules, and special notes on local CLI calling.

## Overview

Telnyx offers detailed insights and resources for number portability across multiple international regions. This page consolidates the country-specific documentation requirements, Letter of Authorization (LoA) templates, and procedural notes needed to port international numbers into Telnyx, as well as the broader set of documents required to order international numbers.

## Submitting International Port Requests via Telnyx Portal

To check the portability status of international numbers, submit your port request via your Telnyx Portal account along with the documentation required for the destination country. Upon submission, you will be required to provide an LoA and invoice. Once portability has been confirmed across coverage and carrier, the porting team will get back to you with the next steps required to port the number(s) along with any other documentation requirements needed.

## International Number Requirements Tool

The International Number Requirements Tool is available in the Telnyx Portal at the [requirements page](https://portal.telnyx.com/#/app/numbers/requirements?enableAlerts=true). It allows users to view the supplemental information or documentation required to activate numbers ahead of time, helping customers better plan number ports and orders and avoid unforeseen wait times.

To use the tool, filter by the country or countries where you want to buy a number, click **Apply Filters**, then click on the returned result. You will see a list of all relevant documents needed to acquire or port a Local, National, Mobile, or Toll-Free number for that country.

Note: The tool only retrieves information on numbers in regions that require supplemental information for number porting and ordering. Countries with no requirements will return as null. For country coverage questions, contact the [Telnyx sales team](https://telnyx.com/contact-us).

## Country-Specific Porting Requirements

### Austria

**Local and National Numbers**
1. LoA (local address required)
2. Account Number
3. ID / Passport copy
4. Company Registration certificate
5. Latest Invoice
6. Proof of address

**Toll-Free Numbers**
1. LoA
2. Current underlying carrier's name
3. Porting history (if the number(s) were ported before)
4. Account Number
5. Latest Invoice

Download the Austria LoA [here](http://assets.ctfassets.net/taysl255dolk/5bvRirKjh7u8TWy0LkYiSc/c3d9da4269c2158f0e67496068a895e4/Rufnummernmitnahme_KDB_TELNYX.pdf).

### Belgium

**Local Numbers**
1. LoA (local address required; the area code of the number must match the address to register on file)
2. VAT / TAX ID
3. Latest Invoice
4. Proof of local address

**National and Toll-Free Numbers**
1. LoA (national address required)
2. VAT / TAX ID
3. Latest Invoice
4. Proof of local address

Download the Belgium LoA [here](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

### Czech Republic

For Local / National / Toll-Free number types:
1. LoA (local service address)
2. OKU (migration code)
3. Latest Invoice
4. VAT / TAX ID
5. Proof of address

Contact [porting@telnyx.com](mailto:porting@telnyx.com) for the LoA template for porting in the Czech Republic.

### Hungary

For all number types:
1. LoA with account number
2. VAT / TAX ID
3. Latest Invoice
4. Company Registration Certificate
5. Passport or ID copy of the Authorized Person

Contact [porting@telnyx.com](mailto:porting@telnyx.com) for the LoA template for porting in Hungary.

### Israel

For Local / National / Mobile numbers:
1. LoA
2. VAT / TAX ID
3. Latest Invoice

If porting a **Mobile** number under a business, the invoice must be from the underlying carrier, and an official proof of ownership signed by the underlying carrier will be required to successfully port the numbers.

Download the Israel LoA [here](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

### Luxembourg

For Local, National, and Toll-Free number types:
1. LoA
2. VAT / TAX ID
3. Local contact phone number
4. Latest Invoice

Download the Luxembourg LoA [here](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

### Netherlands

**Local Numbers and Smart Mobile (+31 97) Numbers**
1. LoA (user's local address from the same city as the number to be ported)
2. Latest Invoice
3. Copy of company Registration certificate for business / Copy of ID for personal
4. Proof of local address

**National Numbers**
1. LoA (national address required)
2. Latest Invoice
3. Copy of company Registration certificate for business / Copy of ID for personal
4. Proof of local address
5. Number allocation document ("OPTA/ACM Beschikking") — applies only to +3188

**Toll-Free Numbers**
1. LoA
2. Latest Invoice
3. ID / Passport copy
4. Company Registration certificate

Download the Netherlands LoA [here](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

**Partial Porting in the Netherlands:** Not all carriers in the Netherlands agree to partial port or split a number block. If the number you are looking to port is associated to a full range, either the full range must be ported or Telnyx can attempt a partial port. However, all numbers that are part of the range that are set to remain with the current provider will be down for an indeterminate period on FOC.

**Porting out of Telnyx:** The gaining provider must submit a request to Telnyx. Once the request is received, Telnyx will create a Port out request in the end-user's Portal. This request must be authorized within 2 business days by the end-user. Once the port out is authorized on the end-user's end, Telnyx will approve the port out with the gaining provider.

### Norway

For Local / National / Toll-Free numbers:
1. LoA (a local address is mandatory)
2. Latest Invoice
3. Local TAX ID / VAT

Download the Norway LoA [here](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

Number porting allows businesses and individuals in Norway to retain their existing phone numbers when switching to a new service provider, ensuring continuity and reducing the hassle of updating contact details. The porting process can vary from 1 to 7 business days depending on factors that influence timelines.

### Romania

For Local and Toll-Free number types:
1. LoA
2. Latest Invoice
3. Company Registration Certificate
4. Copy of Authorized Person's ID or Passport
5. VAT / TAX ID

Download the Romania LoA [here](https://assets.ctfassets.net/taysl255dolk/5FZ4qUVt9KGSMsGzbMK6zm/c09622fb44aac104169c67344c25dcf1/Portability_Form_-_Telnyx_-_Romania.pdf).

### Slovakia

For Local, National, and Toll-Free number types:
1. LoA
2. VAT / TAX ID
3. Latest Invoice

Download the Slovakia LoA [here](https://assets.ctfassets.net/taysl255dolk/1od8xuO7Y7WKUrIlXXCM2t/57023f6b1ab4e56954597cfeb5151aa4/Slovakia_telnyx.pdf).

### Slovenia

For Local / National and Toll-Free number types:
1. LoA
2. VAT / TAX ID
3. Latest Invoice with the current provider

Download the Slovenia LoA template [here](https://www.dropbox.com/home/International%20Porting%20Documentation/Slovenia?preview=LOA+-+Telnyx+-+Slovenia+-+ENG.docx).
