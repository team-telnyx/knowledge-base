## Exhausted NPAs

A Numbering Plan Area (NPA) is the three-digit area code identifying a region in North America. An **exhausted NPA** is one where nearly all numbering resources are assigned. The industry addresses this via an **overlay** — adding a new area code to the same geographic region, requiring 10-digit dialling.

When ordering numbers in a desirable area code with limited availability, expanding your search to include overlay codes can help. For example, New York City's 212 was exhausted in 2010, so 917 and 646 were added as overlays — all serving the same geographic area.

A comprehensive list of exhausted NPAs is maintained in the [Exhausted NPA guide](https://support.telnyx.com/en/articles/4640720-what-is-an-exhausted-npa), covering area codes across US states and Canadian provinces.
