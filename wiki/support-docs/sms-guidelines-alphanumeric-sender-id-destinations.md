# SMS Guidelines: Alphanumeric Sender ID Destinations

Consolidated Telnyx SMS guidelines for destinations where Alphanumeric Sender IDs are supported without registration and no destination-specific content restrictions apply, including MCC and dial code for each country or territory.

## Overview

This page consolidates Telnyx SMS guidelines for a set of destinations where Alphanumeric Sender IDs are supported and maintained without registration, and where there are no content restrictions beyond the standard [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md). Each destination below lists its Mobile Country Code (MCC) and international dial code.

## Italy

- **MCC:** 222
- **Dial Code:** 39
- Alphanumeric Sender IDs are supported and will be maintained; no registration is required.
- No content restrictions apply to this destination.
