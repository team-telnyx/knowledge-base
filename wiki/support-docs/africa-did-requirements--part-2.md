# Africa DID Requirements

*Part 2 of 2 — see also: [Part 1](africa-did-requirements--part-1.md)*

Requirements for purchasing Telnyx DID numbers across African countries, organized by country and number type. Each country has distinct identity, business, and address verification requirements that must be met before numbers can be activated.

## South Africa

Activation for all South Africa number types takes approximately 72 hours after documentation is received.

### Local Numbers

**Personal identity** verification:
- Name, last name
- Contact phone number
- Passport or South African ID copy

**Business identity** verification:
- Name, last name of an authorized representative
- Contact phone number
- Passport or South African ID copy of an authorized representative
- Company name
- Company registration certificate

**Address** verification:
- Address matching the DID area code (street, building number, postal code, city and country)
- Proof of address (dated within 3 months)

### National Numbers

**Personal identity** verification:
- Name, last name
- Contact phone number
- Passport or South African ID copy

**Business identity** verification:
- Name, last name of an authorized representative
- Contact phone number
- Passport or South African ID copy of an authorized representative
- Company name
- Company registration certificate

**Address** verification:
- Address within South Africa (street, building number, postal code, city and country)
- Proof of address (dated within 3 months)

### Mobile Numbers

**Personal identity** verification:
- Name, last name
- Contact phone number
- Passport or ID copy

**Business identity** verification:
- Name, last name of an authorized representative
- Company name
- Contact phone number
- Company registration certificate

**Address** verification:
- Address worldwide (street, building number, postal code, city and country)
- Proof of address (dated within 3 months)

### Toll-Free Numbers

**Personal identity** verification:
- Name, last name
- Contact phone number
- Passport or South African ID copy
- Signed LOI (dated within 1 month)

**Business identity** verification:
- Name, last name of an authorized representative
- Contact phone number
- Passport or South African ID copy of an authorized representative
- Company name
- Company registration certificate
- Signed LOI (dated within 1 month)

**Address** verification:
- Address worldwide (street, building number, postal code, city and country)
- Proof of address (dated within 3 months)

**Business identity** verification:

**Address** verification:

- Proof of address (dated within 3 months)

## Common Patterns

Several requirements appear across multiple African countries:

- **Proof of address** is commonly required to be dated within the last 3 months.
- **LOI (Letter of Intent)** is required for certain number types in Ghana (national), Mozambique (mobile), Nigeria (national), South Africa (toll-free), and Uganda (toll-free). Telnyx provides an LOI template.
- **Business-use-only restrictions** apply to Kenya (all types), Nigeria (national), and Rwanda (local).
- **72-hour activation** is standard for Benin, Cameroon, Congo, Rwanda, South Africa, and Zambia after all documentation is submitted.
- **Local address requirements** (address within the country or matching the DID area code) apply to South Africa (local and national numbers), Uganda (national numbers), and Zambia (mobile numbers). Most other countries accept a worldwide address.
