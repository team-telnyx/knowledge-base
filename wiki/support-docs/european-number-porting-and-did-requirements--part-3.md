# European Number Porting and DID Requirements

*Part 3 of 4 — see also: [Part 1](european-number-porting-and-did-requirements--part-1.md), [Part 2](european-number-porting-and-did-requirements--part-2.md), [Part 4](european-number-porting-and-did-requirements--part-4.md)*

This page consolidates Telnyx's documentation for number porting and DID acquisition across Denmark, Finland, Ireland, the United Kingdom, Sweden, Georgia, Latvia, Russia, Ukraine, Poland, Lithuania, and Estonia. It covers the documentation required to port existing numbers into Telnyx, the identity and address verification needed to purchase new DIDs, and country-specific operational notes such as porting hours, SLAs, and common rejection causes.

## Latvia DID Requirements

To purchase a Latvia number, the following must be provided.

### Local Numbers in Latvia

For **business identity** verification:

- Name, last name of an authorized representative.
- Contact phone number.
- Company name.
- Copy of ID or Passport of an authorized representative.
- Company registration certificate.

For **address** verification:

- Address in Latvia (street, building number, postal code, city, and country).
- Proof of address (dated within 3 months).

Business use is required; private use is not allowed.

### Toll-Free Numbers in Latvia

For **personal identity** verification:

- Name, last name.
- Contact phone number.

For **business identity** verification:

- Name, last name of an authorized representative.
- Company name.
- Contact phone number.

For **address** verification:

- Address in Latvia (street, building number, postal code, city, and country).

## Russia DID Requirements

### Mobile Numbers in Russia

For **business identity** verification:

- Name, last name of an authorized representative.
- Company name.
- Contact phone number.
- Passport or ID copy of an authorized representative.
- Business Registration Certificate.
- Signed LOI (dated within 1 month).

For **address** verification:

- Worldwide address (street, building number, postal code, city, and country).
- Proof of address matching the address in the Business Registration Certificate (dated within 3 months).

Business use is required; private use is not allowed. Once the documentation is received, it will take approximately 72 hours to validate the information and activate the number for use.

## Latvia Number Porting

For local and national number types in Latvia, the following are required:

1. LoA.
2. Latest invoice.
3. ID number of the authorized person.
4. Company registration number (only if the number belongs to a company).

Download the Latvia LoA from the [Telnyx international LoA template](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

## Poland Number Porting

For local and national number types in Poland, the following are required:

1. LoA — for local numbers, the address must be within the same area as the phone number to be ported.
2. VAT / TAX ID (NIP) for business, or PESEL for personal account.
3. Company Registration Certificate (for business only).
4. Latest invoice with the current carrier.
5. ID / Passport copy of the authorized person.

Download the [Poland authorization letter](https://assets.ctfassets.net/taysl255dolk/1oEnZQgZI2KjrRJ9xiSFPk/4b4fa33b8cb5199be0bd33ab8b00c58f/Poland_LOA_-_Telnyx_.pdf).

## Lithuania Number Porting

For local, national, and toll-free number types in Lithuania, the following are required:

1. LoA.
2. Latest invoice.
3. VAT / TAX ID if the number belongs to a company; otherwise, a Personal ID code (asmens kodas) is required.

Download the [Lithuania LoA](https://assets.ctfassets.net/taysl255dolk/d30N9jIww0vlZyFZrovAP/58d1196eba9eb350947708a2de8bc840/Lithuania_Loa_-_Telnyx.pdf).
