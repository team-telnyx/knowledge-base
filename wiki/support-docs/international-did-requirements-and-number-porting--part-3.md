# International DID Requirements and Number Porting

*Part 3 of 4 — see also: [Part 1](international-did-requirements-and-number-porting--part-1.md), [Part 2](international-did-requirements-and-number-porting--part-2.md), [Part 4](international-did-requirements-and-number-porting--part-4.md)*

This page consolidates Telnyx's documentation requirements for acquiring new DID numbers and porting existing numbers across multiple countries, including Spain, Germany, Austria, Israel, Italy, the Netherlands, Switzerland, the United Kingdom, Bolivia, South Africa, Argentina, and Hungary. It covers identity, business, and address verification requirements, country-specific porting procedures, timelines, and key operational considerations such as contract termination, partial porting, and physical presence rules.

## Italy Number Porting

### Local / National Numbers

1. LOA (local address required)
2. Local TAX / VAT ID or company registration number
3. Migration code
4. Latest invoice
5. A copy of the passport / ID of the authorized person
6. Fiscal code of the authorized person (an alphanumeric code of 16 characters)
7. Proof of local address

There must be a local address in Italian territory and a legal presence (with a valid fiscal code) to port in Italy.

### Toll-Free Numbers

1. LOA (local address required)
2. Local TAX / VAT ID or company registration number
3. Latest invoice
4. A copy of the passport / ID of the authorized person
5. Proof of local address

### Cancellation and Postponement

Once the losing carrier has given confirmation for porting, the porting request can be canceled or postponed:
- For standard ports, at the latest 5 working days before the port date. After that period, the port will go ahead without possibility of fallback.
- For mixed operator/complex ports, at the latest 7 working days before the port date. After that period, the port will go ahead without possibility of fallback.

Outage during porting may occur.

See also [Italy Number Porting](italy-number-porting.md).

## Netherlands Number Porting

### Local Numbers and Smart Mobile (+31 97) Numbers

1. LOA (user's local address from the same city as the number to be ported)
2. Latest invoice
3. Copy of company registration certificate for business / copy of ID for personal
4. Proof of local address

### National Numbers

1. LOA (national address required)
2. Latest invoice
3. Copy of company registration certificate for business / copy of ID for personal
4. Proof of local address
5. Number allocation document ("OPTA/ACM Beschikking") — this only applies to +3188

### Toll-Free Numbers

1. LOA
2. Latest invoice
3. ID / passport copy
4. Company registration certificate

### Partial Porting

Not all carriers in the Netherlands agree to partial port/split a number block. If the number you are looking to port is associated to a full range, either the full range must be ported or Telnyx can attempt to partial port. However, all numbers that are part of the range that are set to remain with the current provider will be down for an indeterminate period on FOC.

### Porting Out of Telnyx

The gaining provider must submit a request to Telnyx. Once the request is received, Telnyx will create a Port out request in the end-user's Portal. This request must be authorized within 2 business days by the end-user. Once the port out is authorized on the end-user's end, Telnyx will approve the port out with the gaining provider.

See also [Netherlands Number Porting](netherlands-number-porting.md).

## Switzerland Number Porting

### Local / National Numbers

1. LOA (porting wish date must be mentioned; the signature must be a wet signature) — if porting numbers under a business, the authorized person must have full authority to act on behalf of that business
2. Latest invoice
3. VAT / TAX ID
4. Proof of address dated within 3 months of request (latest invoice / utility bill / insurance)

### Toll-Free Numbers

1. LOA (porting wish date must be mentioned)
2. Latest invoice
3. Ownership proof from BAKOM (with reference number)

A single number belonging to a DDI range cannot be ported out separately. In order for a DDI range to be ported, it must include at least 10 successive numbers or a multiple of it. The first number of the range must end with 0 and the last number of the range must end with 9. These details are available with the current provider.

See also [Switzerland Number Porting](switzerland-number-porting.md).
