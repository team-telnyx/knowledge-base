This page covers how to configure Telnyx as a SIP provider for Thirdlane and 3CX (V18 and V20) PBX systems, including trunk creation, inbound/outbound routing, caller ID, SMS gateway setup, and compatibility considerations between 3CX and Telnyx.

## Overview

This page covers how to configure Telnyx as a SIP provider for two popular multi-tenant and Unified Communications PBX platforms: Thirdlane and 3CX. It also documents the compatibility considerations between 3CX and Telnyx, including the move from the legacy Telnyx Messaging API configuration to the 3CX generic template.
