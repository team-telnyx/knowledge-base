# SMS Guidelines: Selected Destinations

Consolidated Telnyx SMS guidelines for 15 destinations, covering MCC, dial codes, alphanumeric sender ID support, registration requirements, content restrictions, and sender ID recommendations.

## Overview

This page consolidates Telnyx SMS guidelines for the following destinations: Moldova, Cyprus, Dominica, Eritrea, Ethiopia, Gambia, Guam, Mauritania, Montserrat, Palau, Papua New Guinea, Senegal, Sierra Leone, Somalia, and Vanuatu. Each entry lists the Mobile Country Code (MCC), international dial code, alphanumeric sender ID support, registration requirements, and any content or sender ID restrictions that apply when sending SMS through Telnyx.

## Moldova

- **MCC:** 259
- **Dial Code:** 373
- Alphanumeric Sender IDs are supported and will be maintained; no registration is required.
- There are no restrictions with regards to content towards this destination.

## Cyprus

- **MCC:** 357
- **Dial Code:** 280
- Alphanumeric Sender IDs are supported and will be maintained; no registration is required.
- There are no restrictions with regards to content towards this destination.

## Dominica

- **MCC:** 366
- **Dial Code:** 1767
- Alphanumeric Sender IDs are supported and will be maintained; no registration is required.
- There are no restrictions with regards to content towards this destination.

## Eritrea

- **MCC:** 657
- **Dial Code:** 291
- Alphanumeric Sender IDs are supported and will be maintained; no registration is required.
- The use of generic Alpha Sender IDs is not recommended. Alpha Senders should be directly related to the message content.
- Religious, political, or adult traffic is prohibited.

## Ethiopia

- **MCC:** 636
- **Dial Code:** 251
- Alphanumeric Sender IDs are supported.
- For network MTN (63601), Alphanumeric Sender IDs are only supported with registration. Without registration to this network, Alpha Senders will be overwritten to Generic Alpha Sender IDs or will not deliver.
- Sending traffic related to local banking or promotional traffic is not allowed.
- For more information on Alpha Sender ID registration, contact [alpha_sender_id@telnyx.com](mailto:alpha_sender_id@telnyx.com).

## Guam

## Acceptable Use

All destinations listed above are subject to the Telnyx [Acceptable Use Policy for Messaging](https://support.telnyx.com/en/articles/1310359-acceptable-use-policy-for-messaging). Always refer to this policy when planning messaging traffic to any of these destinations.
