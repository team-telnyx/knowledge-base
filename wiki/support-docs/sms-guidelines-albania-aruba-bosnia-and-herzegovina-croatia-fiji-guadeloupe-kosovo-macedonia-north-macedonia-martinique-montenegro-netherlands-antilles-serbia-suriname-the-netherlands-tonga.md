# SMS Guidelines: Albania, Aruba, Bosnia and Herzegovina, Croatia, Fiji, Guadeloupe, Kosovo, Macedonia (North Macedonia), Martinique, Montenegro, Netherlands Antilles, Serbia, Suriname, The Netherlands, Tonga

Consolidated Telnyx SMS guidelines for Albania, Aruba, Bosnia and Herzegovina, Croatia, Fiji, Guadeloupe, Kosovo, Macedonia (North Macedonia), Martinique, Montenegro, Netherlands Antilles, Serbia, Suriname, The Netherlands, and Tonga, including MCC, dial code, and Alphanumeric Sender ID requirements.

## Overview

This page consolidates Telnyx SMS guidelines for a set of destinations where Alphanumeric Sender IDs are supported without registration. For each destination, the relevant Mobile Country Code (MCC), international dial code, and any sender ID or content restrictions are listed. All destinations also reference Telnyx's [Acceptable Use Policy for Messaging](acceptable-use-policy-for-messaging.md).

## Albania

- **MCC:** 276
- **Dial Code:** 355
- Alphanumeric Sender IDs are supported and will be maintained; no registration is required.
- There are no restrictions with regards to content towards this destination.

## Aruba

- **Dial Code:** 297
- Alphanumeric Sender IDs are supported and will be maintained; no registration is required.
- There are no restrictions with regards to content towards this destination.

- **Dial Code:** 599

- There are no restrictions with regards to content towards this destination.

## Serbia

- **MCC:** 220
- **Dial Code:** 381
- Alphanumeric Sender IDs are supported **with registration**.
- Registration is possible to ensure Alphanumeric Senders can be maintained. Without registration, Alpha Senders will be overwritten to Generic Alpha Sender IDs.
- The registration of Alphanumeric Senders involves monthly fees.
- For more information on Alpha Sender ID registration, contact [alpha_sender_id@telnyx.com](mailto:alpha_sender_id@telnyx.com).
