# European & Mediterranean DID and Number Porting Requirements

*Part 2 of 3 — see also: [Part 1](european-mediterranean-did-and-number-porting-requirements--part-1.md), [Part 3](european-mediterranean-did-and-number-porting-requirements--part-3.md)*

This page consolidates Telnyx's documentation, identity verification, and porting requirements for acquiring and porting DID numbers across the United Kingdom, Ireland, Turkey, Croatia, Germany, Greece, Italy, Cyprus, Switzerland, Malta, and Albania. It covers the documents required for new number purchases (personal/business identity and address verification) and for porting existing numbers (LOA, invoices, IDs, and country-specific forms), along with EU rules on what counts as a "local" identity document.

## Identity Verification: What "Local" Means

For most orders, proof of identity must be issued by the country in which the purchase is being made. As an exception, customers within the European Union may use a valid passport or national identity card from any EU member state, even if it differs from the EU country associated with the order; in these cases, the document will be treated as local.

All identification is subject to review, and Telnyx reserves the right to request additional documentation or decline any document that cannot be verified or that does not meet applicable legal and regulatory requirements.

## Croatia Number Porting

**Local / National Numbers** require:
1. LOA
2. ID / Passport copy
3. Company registration certificate
4. Latest invoice

**Toll-Free Numbers** require:
1. LOA
2. ID / Passport copy / Company registration certificate
3. Latest invoice

The Croatia LOA can be downloaded from the [Croatia Porting Form](https://www.dropbox.com/s/1kd2hs03tq8o0bg/Croatia_Porting_Form.pdf?dl=0).

## Germany Number Porting

Number portability in Germany follows strict rules and procedures.

**Number length:**
- Numbers in Berlin, Frankfurt, Hamburg, and Munich have a standard length of 10 digits (excluding leading 0)
- Numbers in other municipalities have a standard length of 11 digits (excluding leading 0)

**Extensions:** If a number is longer than 10/11 digits, it is an extended version (typically a 10-block or 100-block). The whole block extension will not be ported — only the standard number itself.

**Local / National Numbers** require:
1. Porting form (local address from the same city as the number to be ported)
2. Latest invoice (from the current provider)
3. Proof of address
4. ID / Passport copy / Company registration certificate

The local/national porting form can be downloaded from the [German porting document and address confirmation](https://www.dropbox.com/s/4d6jx7izmgaiun4/german-porting-document-and-address%20confirmation.pdf?dl=0).

**Toll-Free Numbers** require:
1. Porting form (local address required within Germany)
2. Latest invoice from the current provider (only if the current provider is a reseller)
3. Number allocation document ("Zuteilungsbescheid")
4. ID / Passport copy / Company registration certificate

The toll-free porting form can be downloaded from the [TFN LOA](https://assets.ctfassets.net/taysl255dolk/1tsn59edoZYrYtwIzaKYd0/f4563a1894c76e07a588eb32e364999e/TFN_LOA.pdf).

**Porting hours:** Germany porting requests are scheduled during the standard porting window (6 AM local to 8 AM local). On FOC, the port is triggered by Telnyx porting agents with the carrier at 6 AM local; the carrier then has 2 hours to release the number(s). Porting outside of the standard window is not available.

**Important notes before completing the porting form(s):**
- Maximum of 10 numbers per porting form and/or 1 range
- For each city being ported, a different form is required including the address within each city
- For each donor carrier, a different form is required
- Confirm the number(s) details with the current provider
- If there is a connection assigned to the number(s)

**Contract type:** Numbers cannot be ported until the end of the contract period with the current operator. Future-dated contracts require notifying the carrier of intent to port before submitting the port to Telnyx. Early termination fees may apply.

**Termination of connections:** If a connection is assigned to the DID(s), the details of the port must be discussed with the current provider prior to submitting a request with Telnyx. Once the DID(s) port to Telnyx, any remaining connection will be terminated.

**Porting out of Telnyx:** The gaining provider must submit a request by email to [porting.intl@telnyx.com](mailto:porting.intl@telnyx.com) providing the Standard German Porting Form. Telnyx will create a port-out request in the end-user's Portal, which must be authorized within 4 business days by the end-user.

## Greece Number Porting

**Local Number Types** require:
1. LOA
2. Greek TAX / VAT ID or company registration number
3. ID / Passport copy
4. Company registration certificate
5. Latest invoice with the current carrier (numbers must be indicated on the invoice)

The Greece LOA can be downloaded from the [Telnyx INTL LoA](http://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

## Italy Number Porting

**Local / National Numbers** require:
1. LOA (local address required)
2. Local TAX / VAT ID or company registration number
3. Migration code
4. Latest invoice
5. A copy of the passport / ID of the authorized person
6. Fiscal code of the authorized person (an alphanumeric code of 16 characters)
7. Proof of local address

There must be a local address in Italian territory and a legal presence (with a valid fiscal code) to port in Italy.

**Toll-Free Numbers** require:
1. LOA (local address required)
2. Local TAX / VAT ID or company registration number
3. Latest invoice
4. A copy of the passport / ID of the authorized person
5. Proof of local address

The Italy LOA can be downloaded from the [LoA TELNYX Italy](https://assets.ctfassets.net/taysl255dolk/45LOLnr1ZO8PfWfHpAID9z/cf24bfaa49a0fc3d04900d5c0f9dfac5/LoA_TELNYX_Italy.pdf).

**Cancellation/postponement:** Once the losing carrier has given confirmation for porting, the porting request can be canceled or postponed:
- For standard ports, at the latest 5 working days before the port date
- For mixed operator/complex ports, at the latest 7 working days before the port date

After those periods, the port will go ahead without possibility of fallback. Outage during porting may occur.

## Cyprus Number Porting

**Local Number Types** require:
1. LoA (with local address)
2. Latest invoice with the current carrier
3. Company registration (if the number belongs to a company)
4. ID or passport number of the legal representative
5. Proof of address

**National and Toll-Free Number Types** require the same documents, except the LoA must include a national address.

The Cyprus LOA can be downloaded from the [Cyprus LoA - Telnyx](https://assets.ctfassets.net/taysl255dolk/1Cq2IXxuZiFRu03aA3LXB6/8006b5ee40f97ac95f050be7013c8bcb/CYPRUS_LOA-_Telnyx.pdf).

## Switzerland Number Porting

**Local / National Numbers** require:
1. LOA (porting wish date must be mentioned; signature must be a wet signature) — if porting under a business, the authorized person must have full authority to act on behalf of that business
2. Latest invoice
3. VAT / TAX ID
4. Proof of address dated within 3 months of request (latest invoice, utility bill, or insurance)

**Toll-Free Numbers** require:
1. LOA (porting wish date must be mentioned)
2. Latest invoice
3. Ownership proof from BAKOM (with reference number)

A single number belonging to a DDI range cannot be ported out separately. For a DDI range to be ported, it must include at least 10 successive numbers or a multiple thereof. The first number of the range must end with 0 and the last number of the range must end with 9.

The Switzerland LOA can be downloaded from the [Telnyx INTL LoA](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf).

## Albania Number Porting

**Local / National Number Types** require:
1. LoA
2. TAX ID / VAT or company registration number
3. Latest invoice
4. Copy of authorized person's ID or passport

Contact [porting@telnyx.com](mailto:porting@telnyx.com) for the LoA template for porting in Albania.
