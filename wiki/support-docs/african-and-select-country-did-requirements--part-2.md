# African and Select Country DID Requirements

*Part 2 of 2 — see also: [Part 1](african-and-select-country-did-requirements--part-1.md)*

This page consolidates Telnyx's documentation requirements for acquiring Direct Inward Dialing (DID) numbers across a range of countries, primarily in Africa, plus a few additional jurisdictions. It covers identity, address, and supporting documentation needed for personal and business verification, along with activation timelines and country-specific restrictions such as business-use-only rules.

## Nigeria

### National Numbers

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number
- Signed LOI (dated within 1 month)

**Address verification:**
- Worldwide address (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

**Additional information:**
- Service usage description
- Business use is required; private use is not allowed.

### Toll-Free Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number

**Address verification:**
- Worldwide address (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

## Rwanda

### Local Numbers

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number
- Company registration certificate

**Address verification:**
- Address worldwide (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

Business use is required; private use is not allowed.

## Uganda

### Local Numbers

**Personal identity verification:**
- Name, last name

**Business identity verification:**
- Name, last name of an authorized representative
- Company name

**Address verification:**
- Address worldwide (street, building number, postal code, city, and country)

### National Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number
- Passport or ID copy

**Business identity verification:**
- Name, last name
- Contact phone number
- Company name
- Company incorporation certificate copy

**Address verification:**
- Address in Uganda (street, building number, postal code, city, and country)
- A copy of a utility bill (less than 3 months old)

### Toll-Free Numbers

**Personal identity verification:**
- Name, last name
- Contact e-mail
- Passport or ID copy
- Signed LOI (dated within 1 month)

**Business identity verification:**
- Name, last name of an authorized representative
- Contact e-mail
- Company name
- Copy of Business Extract (dated within 3 months)
- Signed LOI (dated within 1 month)

**Address verification:**
- Address worldwide (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

## Zambia

### Mobile Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number
- Contact e-mail
- Passport or ID copy

**Business identity verification:**
- Name, last name of an authorized representative
- Contact phone number
- Contact e-mail
- Company name
- Company registration certificate

**Address verification:**
- Address in Zambia (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

**Additional information:**
- Service usage description

## Activation Timeline

For most countries listed, once documentation is received, Telnyx takes approximately 72 hours to validate the information and activate the number for use. This applies to Albania, Benin, Cameroon, Congo, Estonia, Guatemala, Rwanda, and Zambia. Other countries (Ghana, Israel, Jamaica, Kenya, Nigeria, Uganda) follow similar validation processes but timelines should be confirmed at order time.
