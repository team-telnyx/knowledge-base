# Caribbean: SMS Guidelines

Country-by-country SMS requirements for 15 Caribbean destinations, including MCC, dial codes, and alphanumeric sender ID rules (support, registration, and possible overwrites). Always comply with Telnyx’s Acceptable Use Policy for Messaging; registration assistance is available via alpha_sender_id@telnyx.com where required.

## General guidance
- MCC = Mobile Country Code; Dial Code = country/area calling code used for international routing.
- Delivery policies can vary by operator. In some markets, unregistered alphanumeric sender IDs may be overwritten to a local long code or short code to ensure delivery.
- Always adhere to Telnyx’s Acceptable Use Policy for Messaging: https://support.telnyx.com/en/articles/1310359-acceptable-use-policy-for-messaging
- For sender ID registration needs, contact: mailto:alpha_sender_id@telnyx.com

## Anguilla
- MCC: 365 | Dial Code: 1264
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.

## Antigua and Barbuda
- MCC: 344 | Dial Code: 1268
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.

## Aruba
- MCC: 363 | Dial Code: 297
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.

## Bahamas
- MCC: 364 | Dial Code: 1242
- All alphanumeric sender IDs are overwritten to a random local long code or short code to ensure delivery.

## Barbados
- MCC: 342 | Dial Code: 1246
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.

## Bermuda
- MCC: 350 | Dial Code: 1441
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.

## Cayman Islands
- MCC: 346 | Dial Code: 1345
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.

## Cuba
- MCC: 368 | Dial Code: 53
- Alphanumeric sender IDs supported only with prior registration.
- Mixed-character sender IDs (letters + numbers) are not supported; use alphabetic only.
- Provisioning time for alpha sender ID registration can be up to 6 months.
- Registration assistance: mailto:alpha_sender_id@telnyx.com

## Dominica
- MCC: 366 | Dial Code: 1767
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.

## Dominican Republic
- MCC: 370 | Dial Code: 1809
- Alphanumeric sender IDs supported; no registration required.
- Sender IDs may occasionally be overwritten to a random short code to ensure delivery.

## Grenada
- MCC: 352 | Dial Code: 1473
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.

## Guadeloupe
- MCC: 340 | Dial Code: 590
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.

## Haiti
- MCC: 372 | Dial Code: 509
- Alphanumeric sender IDs supported.
- Network NATCOM (37203): alphanumeric sender IDs require registration. Without registration, sender IDs may be overwritten to a generic alpha or may fail delivery.
- Generic alpha sender IDs are discouraged; the sender should relate directly to message content.
- Registration assistance: mailto:alpha_sender_id@telnyx.com

## Jamaica
- MCC: 338 | Dial Code: 1876
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.

## Martinique
- MCC: 340 | Dial Code: 596
- Alphanumeric sender IDs supported and maintained; no registration required.
- No content restrictions noted.
