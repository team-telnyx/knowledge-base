# SMS Guidelines: Open Sender ID Destinations

Consolidated Telnyx SMS guidelines for destinations where Alphanumeric Sender IDs are supported without registration. Covers MCC, dial codes, sender ID handling nuances, and content restrictions across 15 countries.

## Overview

This page consolidates Telnyx SMS guidelines for destinations where Alphanumeric (Alpha) Sender IDs are supported and generally maintained without requiring pre-registration. Across all destinations listed below, there are no content restrictions, and senders should always comply with the [Acceptable Use Policy for Messaging](https://support.telnyx.com/en/articles/1310359-acceptable-use-policy-for-messaging).

A few destinations include additional caveats around generic Alpha Sender IDs or carrier-specific overwrites, which are noted in the per-country sections.

## Sender ID Notes by Destination

### Standard Alpha Sender ID Support

For Angola, Anguilla, Burkina Faso, Cambodia, Cape Verde, Faroe Islands, Lesotho, Mongolia, Portugal, and Togo, Alphanumeric Sender IDs are supported and will be maintained, with no registration required.

### Generic Alpha Sender ID Not Recommended

For Poland and Greenland, Alphanumeric Sender IDs are supported and maintained without registration, but the use of generic Alpha Sender IDs is not recommended. Alpha Senders should be directly related to the message content.

### Carrier-Specific Overwrites

- **Mozambique (MCC 643):** Alphanumeric Sender IDs are supported. Occasionally an Alpha Sender ID might be replaced by a Generic Alpha Sender ID towards Network Movitel (64303) to ensure delivery. For more information on Alpha Sender ID registration, contact [alpha_sender_id@telnyx.com](mailto:alpha_sender_id@telnyx.com).
- **Namibia (MCC 649):** Alphanumeric Sender IDs are supported and will be maintained, no registration required. Occasionally Alphanumeric Sender IDs might be replaced by a Generic Alphanumeric Sender ID to ensure delivery.
- **Turkmenistan (MCC 438):** All Alphanumeric Sender IDs will be overwritten to either a random Long Code or a Generic Alphanumeric Sender ID to ensure delivery.

## Content Restrictions

For every destination on this page, there are no restrictions with regards to content. Senders must still adhere to the [Acceptable Use Policy for Messaging](https://support.telnyx.com/en/articles/1310359-acceptable-use-policy-for-messaging).
