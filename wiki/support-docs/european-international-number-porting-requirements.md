# European & International Number Porting Requirements

A consolidated reference for phone number porting requirements across various countries in Europe and Israel, detailing the necessary documents, Letter of Authorization (LOA) access, and special conditions for each nation.

## General Requirements

While porting requirements vary by country, most local, national, and toll-free number ports require a standard set of documents. These typically include a Letter of Authorization (LOA), the latest invoice from the current carrier, a VAT or TAX ID, proof of identity (ID or Passport), and a company registration certificate. Ensure that the name and address on your LOA match the current carrier's records exactly.

## Country-Specific Porting Requirements

### Albania
Applicable to Local/National numbers.
- LOA
- TAX ID / VAT or Company Registration Number
- Latest Invoice
- Copy of Authorized Person's ID or Passport
- **LOA Access**: Contact [porting@telnyx.com](mailto:porting@telnyx.com) for the template.

### Croatia
**Local / National Numbers**
- LOA
- ID / Passport copy
- Company Registration certificate
- Latest Invoice

**Toll-free Numbers**
- LOA
- ID / Passport copy / Company Registration Certificate
- Latest invoice
- **LOA Access**: [Croatia Porting Form](https://www.dropbox.com/s/1kd2hs03tq8o0bg/Croatia_Porting_Form.pdf?dl=0)

### Czech Republic
Applicable to Local/National/Toll-free numbers.
- LOA (Local Service address)
- OKU (Migration code)
- Latest Invoice
- VAT / TAX ID
- Proof of address
- **LOA Access**: Contact [porting@telnyx.com](mailto:porting@telnyx.com) for the template.

### Estonia
Applicable to Local/National/Toll-free numbers.
- LOA
- Latest Invoice
- Company Registration number (if business) / Personal code (if private)
- **LOA Access**: Contact [porting.intl@telnyx.com](mailto:porting.intl@telnyx.com) for the template.

### Greece
Applicable to Local numbers.
- LOA
- Greek TAX / VAT ID or company registration number
- ID / Passport copy
- Company Registration certificate
- Latest Invoice (numbers must be indicated on the invoice)
- **LOA Access**: [Greece LOA](http://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf)

### Hungary
Applicable to all number types.
- LOA with account number
- VAT / TAX ID
- Latest Invoice
- Company Registration Certificate
- Passport or ID copy of the Authorized Person
- **LOA Access**: Contact [porting@telnyx.com](mailto:porting@telnyx.com) for the template.

### Israel
Applicable to Local/National/Mobile numbers.
- LOA
- VAT / TAX ID
- Latest Invoice
- **LOA Access**: [Israel LOA](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf)

### Latvia
Applicable to Local/National numbers.
- LOA

- ID number of the Authorized Person
- Company Registration number (only if the number belongs to a company)
- **LOA Access**: [Latvia LOA](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf)

## Special Porting Conditions

Certain countries have unique rules that must be observed for a successful port:

- **Estonia**: Once a porting request is confirmed (status: FOC confirmed), it is no longer possible to cancel the port. The number would need to be ported back to the original carrier after execution.
- **Israel**: If porting a mobile number under a business, the invoice must be from the underlying carrier. Additionally, an official proof of ownership signed by the underlying carrier is required.
- **Poland**: For local numbers, the address listed on the LOA must be within the same area as the phone number being ported.
- **Norway**: A local address is mandatory on the LOA.
- **Czech Republic**: Requires an OKU (Migration code) and proof of address alongside standard documentation.
