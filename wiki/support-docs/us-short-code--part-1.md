# US Short Code

*Part 1 of 2 — see also: [Part 2](us-short-code--part-2.md)*

A comprehensive guide to ordering, registering, and maintaining compliance for US Short Codes on the Telnyx platform, covering the ordering process, brand and content provider registration, supported carriers, keyword standards, and regulatory marketing and opt-in requirements.

## Ordering Process

There are two types of short code orders:

1. **New Random or Vanity Short Code** — a brand-new code provisioned through Telnyx.
2. **Migration of an existing Random or Vanity Short Code** — moving a code already active at another provider to Telnyx.

### Ordering a New Short Code

To order a new Random or Vanity Short Code, you must complete three forms:

- **Short Code Order Brief** — submitted to the carriers.
- **Brand Registration Form** — submitted to the Short Code Registry (SCR). This must be re-vetted every 12 months.
- **Content Provider Registration Form** — submitted to the SCR. The content provider can be the same entity as the brand.

There is significant overlap between the forms, so filling them out simultaneously is recommended. For current copies of any form, contact [Shortcode@telnyx.com](mailto:Shortcode@telnyx.com).

Once the brief is approved and the brand is registered, it takes approximately **6 weeks** to receive final carrier approval, complete provisioning, and finish testing. This timeline can vary based on volume and season.

### Migrating an Existing Short Code

To migrate an existing short code to Telnyx, you must:

1. Fill out the Short Code Order Brief.
2. Fill out the Brand and Content Provider Registration Form.
3. Provide a Migration Letter.
4. Provide an LOA (Letter of Authorization).
5. Have the current provider transfer the short code to the Telnyx SCR account. Email [shortcode@telnyx.com](mailto:shortcode@telnyx.com) for the Telnyx account ID.

Once documents are approved and accepted, expect approximately **6 weeks** for final carrier approval, testing, and provisioning.

## Brand and Content Provider Registration

The Short Code Registry has introduced a mandatory registration process for both new short code orders and existing short code renewals.

- **New orders:** Brand and Content Provider registration must be complete before the short code can achieve an "active" status. A "parked" short code can be procured during the process, but it cannot be used for messaging until registration is complete.
- **Existing renewals:** Brands that do not complete registration by March 31, 2025 will have a **60-calendar-day grace period** after their first auto-renewal date on or after that date. Short codes not updated within the grace period are subject to compliance enforcement and may be **suspended or terminated**.

### Required Steps

1. Complete the Brand Registration Form.
2. Complete the Content Provider Form.
3. Complete an email verification for both the Brand contact and the Content Provider contact. The verification email is sent by [certify@aegismobile.com](mailto:certify@aegismobile.com) or an address like [noreply@usshortcodes.com](mailto:noreply@usshortcodes.com).

### Definitions

- **Brand:** The perceived sender of the messages (e.g., Nike sending text messages about shoes).
- **Content Provider:** The entity that develops and types the content into the application to send (e.g., a marketing agency hired by Nike). The brand and content provider can be the same entity.

### Important Details

- Information on the registration forms must match the entity's IRS Form CP-575 (EIN Confirmation Letter) to be successful.
- Brand vetting and 2FA verification are redone every year; notify Telnyx if the point of contact changes.
- For up-to-date forms, contact [Shortcode@telnyx.com](mailto:Shortcode@telnyx.com).
