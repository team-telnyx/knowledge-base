# DID Requirements — Central, Eastern & Southeastern Europe

*Part 3 of 3 — see also: [Part 1](did-requirements-central-eastern-southeastern-europe--part-1.md), [Part 2](did-requirements-central-eastern-southeastern-europe--part-2.md)*

A consolidated guide to Telnyx KYC and address requirements for purchasing DID numbers across Albania, Bosnia & Herzegovina, Bulgaria, Croatia, Cyprus, Czech Republic, Hungary, North Macedonia, Poland, Romania, Russia, Serbia, Slovakia, Slovenia, and Ukraine. Requirements are organized by number type (Local, National, Mobile, Toll‑Free) with country‑specific rules, document freshness, and special constraints.

## Tips to speed up approval
- Ensure IDs and company certificates are clear, valid, and where required, issued locally.
- Match geographic addresses precisely to the DID area code when required (street, building number, postal code, city, country).
- Respect document freshness windows (POA within 3 months; utility bills < 6 months where specified).
- Include all special items early: LOI (signed within 1 month), VAT numbers, local national IDs (e.g., PESEL/NIP/REGON/KRS), and service usage descriptions.
- Where physical presence is required, be ready to evidence local presence for the end user purchasing the number.
