# European DID Requirements

*Part 2 of 2 — see also: [Part 1](european-did-requirements--part-1.md)*

A consolidated reference for regulatory requirements when purchasing Telnyx DID numbers across European countries, including identity, business, and address verification details by number type for each jurisdiction.

## Denmark

### Denmark Local Numbers

**Business identity verification only** (no personal option):
- Name, last name of an authorized representative
- Contact phone number
- Contact e-mail
- Company Name
- Business registration certificate
- Business Registration Number

**Address verification:**
- Address in Denmark (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

**Additional details:**
- Business use required; private use is not allowed

### Denmark Mobile Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number

**Address verification:**
- Address worldwide (street, building number, postal code, city, and country)

**Additional information:**
- Service usage description

### Denmark Toll-Free Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number

**Address verification:**
- Address worldwide (street, building number, postal code, city, and country)

## Poland

### Poland Local Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number
- Local Passport or ID copy

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number
- Local Legal papers of company registration

**Address verification:**
- Address matching the DID area code (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

**Additional information:**
- Service usage description
- End-users must be physically present in the country

### Poland Mobile Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number
- Local Passport or ID copy

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number
- Local Company registration certificate

**Address verification:**
- Address in Poland (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

**Additional information:**
- End-users must be physically present in the country

### Poland Toll-Free Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number
- Local Passport or ID copy

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number
- Copy of PESEL, NIP, REGON, KRS or foreign ID of an authorized representative
- Local Company registration certificate

**Address verification:**
- Address in Poland (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

**Additional information:**
- End-users must be physically present in the country
