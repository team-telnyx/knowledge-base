# European DID Requirements

*Part 2 of 3 — see also: [Part 1](european-did-requirements--part-1.md), [Part 3](european-did-requirements--part-3.md)*

This page consolidates Telnyx documentation requirements for acquiring Direct Inward Dialing (DID) numbers across multiple European countries, including Belgium, Netherlands, Bosnia & Herzegovina, Croatia, Czech Republic, Hungary, Latvia, Lithuania, Poland, Slovakia, and Slovenia, as well as Indonesia. It details the identity, business, and address verification documents required for each number type, along with processing timelines and EU-specific identity verification rules.

## Hungary

### Local Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number
- Passport or ID copy

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number
- Company registration certificate

**Address verification:**
- Address matching the DID area code (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

### National Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number
- Passport or ID copy

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number
- Company registration certificate

**Address verification:**
- Address in Hungary (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

### Toll-Free Numbers

**Personal identity verification:**
- Name, last name
- Contact phone number
- Passport or ID copy

**Business identity verification:**
- Name, last name of an authorized representative
- Company name
- Contact phone number
- Company registration certificate

**Address verification:**
- Address in Hungary (street, building number, postal code, city, and country)
- Proof of address (dated within 3 months)

### Poland Number Porting

For local and national number types in Poland, the following are required:

1. Letter of Authorization (LoA). For local numbers, the address must be within the same area as the phone number to be ported.
2. VAT / TAX ID (NIP) for business, or PESEL for personal accounts
3. Company Registration Certificate (business only)
4. Latest invoice with the current carrier
5. ID / Passport copy of the authorized person

The [Poland authorization letter](https://assets.ctfassets.net/taysl255dolk/1oEnZQgZI2KjrRJ9xiSFPk/4b4fa33b8cb5199be0bd33ab8b00c58f/Poland_LOA_-_Telnyx_.pdf) is essential for smooth number porting.
