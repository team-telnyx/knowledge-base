# Telnyx Global Number Requirements and Porting Guide

*Part 3 of 4 — see also: [Part 1](telnyx-global-number-requirements-and-porting-guide--part-1.md), [Part 2](telnyx-global-number-requirements-and-porting-guide--part-2.md), [Part 4](telnyx-global-number-requirements-and-porting-guide--part-4.md)*

A consolidated reference covering Telnyx DID purchase requirements across multiple countries (Turkey, Australia, Uruguay, Cyprus, Greece, Montenegro, Brazil, North Macedonia, Serbia) and number porting procedures for Australia, New Zealand, and Singapore, including document checklists, processing timeframes, and category-specific rules.

## Australia Number Porting

Port Australian phone numbers to Telnyx. This covers requirements, timelines, and the porting process for local, national, toll-free, and mobile numbers.

### Portable Number Types

| Number Type | Portable | Port Category |
| --- | --- | --- |
| Local Numbers | Yes | CAT A or CAT C |
| National Numbers | Yes | CAT A or CAT C |
| Toll-Free (1800) | Yes | CAT Special |
| Mobile (+614) | Yes | Mobile |

### Expected Timeframes

| Port Type | Expected Timeframe |
| --- | --- |
| CAT A (Simple) | 3–6 business days |
| CAT C (Complex) | 5+ weeks |
| CAT Special (Toll-Free) | 3–6 business days |
| Mobile | 1–5 business days |

These are estimates and may be extended depending on order complexity, the losing carrier, or rejections.

### Understanding Port Categories

**CAT A (Simple Port)** is used for straightforward ports: single telephone numbers, "home phone" style numbers, and lines with no complex services attached.

**CAT C (Complex Port)** must be selected if any of the following apply: ISDN lines, hunt groups, PBX services, bundled service packages, or multiple numbers on a single service. Complex services associated with the number(s) will be canceled during the porting process.

**CAT Special** is required for toll-free numbers (1800) and shared cost numbers.

### Document Requirements

For **Local / National / Toll-Free Numbers**:
- LOA — Letter of Authorization with local Australian address
- ABN — Australian Business Number (for business accounts)
- Latest Invoice — from current carrier, dated within the last 30 days

For **Mobile Numbers**:
- LOA — with local Australian address
- Latest Invoice — from current service provider
- Service Type — specify Prepaid or Postpaid
- Identity Documents — 2 forms of Australian Government-issued ID

For prepaid services, also provide the end-user's full name, date of birth, and account number.

Accepted identity documents (2 required): State or Territory Driver's License, Australian Passport, Australian Citizenship Certificate, Proof-of-Age card, Australian Birth Certificate, Foreign military ID card, Current foreign passport with valid entry stamp or visa, Australian Government-issued Photo ID card, or Trade/work/business license.

### Mobile Verification Requirement

Before submitting an Australian mobile port, complete the following verification step:
1. During the port request, reach the "Mobile Verification" step.
2. A unique code is sent to each phone number (via SMS or call).
3. Enter each code to verify ownership of the numbers.
4. All numbers must be verified before the port can proceed.

If not all numbers can be verified, the port will remain in draft status.

### Common Rejection Reasons

| Reason | How to Resolve |
| --- | --- |
| Company information mismatch | Verify exact company name and details with your current carrier before submitting |
| Complex services not declared | Check for hunt groups, ISDN, or bundled services — select CAT C if any exist |
| Associated numbers | Ask current carrier to disassociate linked numbers, or port all associated numbers together |
| Disconnected number | Ensure all numbers are still in-service — do not cancel with current carrier before port completes |

### Changing Your FOC Date

Once a port request reaches FOC confirmed status, date changes require at least 48 business hours notice before the scheduled FOC. Contact Telnyx porting support to request a change.

Porting hours: standard time 8 AM to 12 PM local. For questions, contact [porting@telnyx.com](mailto:porting@telnyx.com).

## New Zealand Number Porting

Port New Zealand phone numbers to Telnyx. This covers requirements, timelines, and the porting process for local and national numbers.

### Portable Number Types

| Number Type | Portable |
| --- | --- |
| Local Numbers | Yes |
| National Numbers | Yes |
| Toll-Free Numbers | Yes |
| Mobile Numbers | Not available |

### Expected Timeframes

Typical processing time from submission to FOC is 5–10 business days for local, national, and toll-free numbers. Actual times may vary based on the losing carrier's responsiveness. A separate table in the source also lists 10+ business days for local, national, and toll-free numbers.

### Document Requirements

- LOA — Letter of Authorization signed by the authorized person
- Latest Invoice — from current carrier, dated within the last 30 days
- Contact Details — full contact information for the authorized person
- Local Address — address within New Zealand is required

For **personal accounts**: full name, contact phone number, and local address within New Zealand.

For **business accounts**: full name of authorized person, contact phone number, company name, and local address within New Zealand.

### Download LOA

[Download the New Zealand Letter of Authorization](https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/c9e0cb60d5051829eb44349be299df79/LoA_-_Telnyx_-_INTL.pdf). The New Zealand LOA uses the same format as the Australian LOA.

Before completing the LOA:
- Save in PDF format (non-editable)
- Fill in all required fields completely
- Ensure information matches your current carrier's records exactly
- Include a valid New Zealand address

### Porting Process

1. Gather all required documents.
2. Submit port request through [Mission Control](https://portal.telnyx.com).
3. Upload LOA and invoice.
4. Telnyx submits request to the losing carrier.
5. Receive FOC confirmation with activation date.
6. Numbers activate on the scheduled FOC date.

Porting hours: Monday to Friday through 2 time slots, 8 AM or 12 PM. For questions, contact [porting@telnyx.com](mailto:porting@telnyx.com).
