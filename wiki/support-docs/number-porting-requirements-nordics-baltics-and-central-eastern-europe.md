# Number Porting Requirements: Nordics, Baltics, and Central/Eastern Europe

A consolidated checklist of Telnyx requirements to port local, national, and toll-free numbers across selected Nordic, Baltic, and Central/Eastern European countries, including LOA templates, identity and business documentation, and country-specific notes.

## Denmark
- Local, National, Toll-Free
  - LOA (local address mandatory; wet signature required)
  - Local TAX ID / VAT
  - Latest invoice with current provider
- LOA template: Download here (international LOA) — https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf

## Finland
- Local, National
  - LOA
  - VAT/TAX ID or Social Security Number
  - Latest invoice
- Toll-Free
  - LOA
  - VAT/TAX ID or Social Security Number
  - Attorney’s authorization for representative (if the number belongs to a company)
  - Latest invoice
- Common rejections
  - Wrong end-user on documentation
  - Signature on LOA not readable/valid
- LOA/POA template: https://assets.ctfassets.net/taysl255dolk/BjAY6YlvDP8UHiRtMAtSP/009510c32ea7832407ab6c525f69478a/FINLAND-TELNYX.pdf

## Sweden
- Local, National, Toll-Free
  - LOA (local address mandatory; wet signature required)
  - Local TAX ID / VAT (must be 12 characters long)
  - Latest invoice
- LOA template: https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf

## Norway
- Local, National, Toll-Free
  - LOA (local address mandatory)
  - Latest invoice
  - Local TAX ID / VAT
- LOA template: https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf

## Latvia
- Local, National
  - LOA
  - Latest invoice
  - ID number of the authorized person
  - Company registration number (if company-owned)
- LOA template: https://assets.ctfassets.net/taysl255dolk/6YYtHkPiDoOfhR8Vp3QxUz/3f7b77cf78ecdebe280c6c0226ac12ea/LoA_-_Telnyx_-_INTL.pdf

## Lithuania
- Local, National, Toll-Free
  - LOA
  - Latest invoice
  - VAT/TAX ID (if company-owned); otherwise Personal ID code (asmens kodas)
- LOA template: https://assets.ctfassets.net/taysl255dolk/d30N9jIww0vlZyFZrovAP/58d1196eba9eb350947708a2de8bc840/Lithuania_Loa_-_Telnyx.pdf

## Estonia
- Local, National, Toll-Free
  - LOA
  - Latest invoice
  - Company registration number (if company-owned) / Personal code (if private customer)
- Important: After FOC (Firm Order Commitment) is confirmed, the port cannot be canceled. To revert, the number must be ported back after completion.
- LOA template: Request via porting.intl@telnyx.com

## Poland
- Local, National
  - LOA (for local numbers, the service address must be within the same area as the number)
  - VAT/TAX ID (NIP) for business; PESEL for personal
  - Company registration certificate (business only)
  - Latest invoice with current carrier
  - ID/Passport copy of the authorized person
- LOA template: https://assets.ctfassets.net/taysl255dolk/1oEnZQgZI2KjrRJ9xiSFPk/4b4fa33b8cb5199be0bd33ab8b00c58f/Poland_LOA_-_Telnyx_.pdf

  - Latest invoice
  - VAT/TAX ID
  - Proof of address
- LOA template: Request via porting@telnyx.com

## General guidance and common pitfalls
- Always include a complete, signed LOA and follow local specifics (e.g., wet signatures and local address in Denmark and Sweden; local address mandatory in Norway; local address must match number’s area for Poland local numbers).
- Ensure the end-user name and legal entity details exactly match the current provider’s records.
- Provide a recent invoice from the current provider with matching account details.
- Include required IDs: VAT/TAX IDs, personal codes, and company registration certificates as specified per country.
- Estonia: post-FOC cancellations are not possible; plan change windows carefully.
- Finland: avoid unreadable or invalid LOA signatures and verify the correct end-user is listed.
