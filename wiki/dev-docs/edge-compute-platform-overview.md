# Edge Compute Platform Overview

Edge Compute is Telnyx's platform of compute primitives for building and deploying applications at the edge, including serverless functions, stateful actors, KV, object storage, and SQL databases (Beta). It combines with Telnyx AI and real-world communication primitives to enable AI agents that act in the physical world.

## Overview

Edge Compute is the platform of compute primitives you use to build and deploy applications to the Telnyx edge — serverless functions, stateful actors, KV, object storage, and [SQL Databases](sql-databases--part-1.md) *(Beta)*.

It is particularly powerful when combined with two other sets of Telnyx primitives to create AI agents that act in the physical world:

- **AI** — [Inference Models](inference-models.md), [Embedding RAG](embedding-rag.md), RAG, memory *(coming soon)*, [Text-to-Speech Overview](text-to-speech-overview.md), [Speech-to-Text Overview](speech-to-text-overview.md), and [Voice Design Lab](voice-design-lab--part-1.md)
- **Real-world communication** — [Voice Overview](voice-overview.md), [Messaging Send Message](messaging-send-message.md), and email *(coming soon)*
