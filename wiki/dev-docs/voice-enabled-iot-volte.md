# Voice-Enabled IoT (VoLTE)

Voice-Enabled IoT (VoLTE) is a Telnyx beta offering that adds a real phone number to any eSIM-capable device, providing a native cellular line with full API control — no second phone, SIP client, or app required.

## Overview

Voice-Enabled IoT (VoLTE) is a Telnyx beta product that lets you add a real phone number to any eSIM-capable device. It delivers a native cellular line with full API control, eliminating the need for a second phone, SIP client, or dedicated app.

## Status

VoLTE is currently in **beta**. A full API reference and detailed configuration documentation are coming soon.

## Key capabilities

- Provision a real phone number on eSIM-capable hardware.
- Operate as a native cellular line rather than a software-based SIP or app client.
- Retain programmatic, API-level control over the line.

## Next steps

Because the product is in beta, the public API reference and configuration guides are not yet available. Refer back to this page for updates as documentation is published.
