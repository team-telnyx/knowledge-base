# Telnyx Reporting

*Part 1 of 4 — see also: [Part 2](telnyx-reporting--part-2.md), [Part 3](telnyx-reporting--part-3.md), [Part 4](telnyx-reporting--part-4.md)*

Telnyx reporting combines the v2 Usage Reports API for aggregated usage data, the Session Analysis API for tree-based per-session cost and event inspection, and On-Demand Reports for natural-language queries against the same usage data.

## Overview

The Telnyx reporting suite provides three complementary ways to inspect and analyze usage data across the platform:

- **Usage Reports API (v2)** — a single, flexible endpoint that returns aggregated usage data across all Telnyx products. It is the foundation for programmatic monitoring of usage trends and costs and for integrating usage data with internal systems.
- **Session Analysis API** — a tree-based view of the full cost and event structure for any individual usage session, especially valuable for AI-powered calls that span multiple Telnyx products.
- **On-Demand Reports** — a natural-language interface in the Mission Control Portal that translates plain-English questions into queries against the v2 Usage Report data.
