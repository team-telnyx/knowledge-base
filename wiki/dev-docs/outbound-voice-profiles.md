# Outbound Voice Profiles

The Telnyx Outbound API lets you create groups of settings and outbound profiles that control how outbound voice traffic is charged, managed, and allowed or disallowed.

## Overview

The Telnyx Outbound API allows you to create groups of settings and outbound profiles that allow you to manage how outbound traffic is charged, managed and allowed or disallowed.

## API Reference

For full details on creating and managing outbound voice profiles, see the [Create an Outbound Voice Profile](https://developers.telnyx.com/api-reference/outbound-voice-profiles/create-an-outbound-voice-profile) endpoint in the API reference.
