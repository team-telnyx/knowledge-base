# Telnyx Wireless for IoT: SIMs, Networking, Voice, Monitoring, and Device Guides

*Part 2 of 2 — see also: [Part 1](telnyx-wireless-for-iot-sims-networking-voice-monitoring-and-device-guides--part-1.md)*

A consolidated guide to building and operating IoT fleets on Telnyx Wireless — covering SIM and eSIM provisioning, lifecycle and group policy, data networking options (public internet and Private Wireless Gateways), traffic filtering and geofencing, usage monitoring and troubleshooting, voice with mobile numbers, AT command basics, and step-by-step device setups.

## AT command basics for modules and Raspberry Pi
- Terminal access: On Linux, use screen or minicom to the correct serial/USB port (e.g., screen /dev/ttyUSB3). List ports with ls -l /dev.
- Common commands (device-specific responses vary):
  - AT: Basic attention; expect OK.
  - AT+COPS=? List available networks; filters to SIM-compatible carriers.
  - AT+COPS=... Manually select a carrier (PLMN selection) or query current.
  - AT+CCID: Read SIM identifier.
  - AT+CREG? Network registration status (and flags via AT+CREG=?).
  - AT+BANDS: Set/inspect band selection (only for advanced troubleshooting).
- Raspberry Pi notes: Enable serial/UART via raspi-config. On some Pi models, USB serial enumeration can be inconsistent; using a Bluetooth keyboard/mouse during setup can avoid confusion about local serial devices.

## Device setup quick starts (APN: data00.telnyx unless noted)
- Cradlepoint IBR200:
  - Access 192.168.0.1 (user: admin; password: device serial). In Connection Manager, add a Modem interface profile. Under SIM/APN/Auth, set APN to data00.telnyx. Save and wait several minutes for attachment (first attach may take up to 30 min).
- Pepwave MAX BR1 Mini:
  - Access 192.168.50.1 (admin/admin). Update firmware. In WAN details → Cellular Settings: LTE/3G Auto, Data Roaming: Any Countries (checked), APN: Custom data00.telnyx. Save & Apply; connect in ~2 minutes.
- GL-MiFi 4G Smart Router:
  - Access 192.168.8.1 (set admin password if prompted). In Cellular Modem manual setup: Device /dev/cdc-wdm0, APN data00.telnyx. Apply and verify IP/usage shows.
- Mikrotik wAP LTE Kit (US):
  - Update RouterOS. Interface → LTE → LTE APNs → Add: Name Telnyx, APN data00.telnyx, IPv4, Use Peer DNS, Add Default Route. Apply to LTE interface, Allow Roaming, insert SIM, verify registration.
- Raspberry Pi 4G HATs:
  - SIM7600-A: Update OS, install libqmi-utils and udhcpc, enable UART. Bring wwan0 up in raw-ip mode, start network with qmicli using APN data00.telnyx, then obtain IP via udhcpc on wwan0.
  - Sixfab Raspberry Pi 3G/4G Base HAT: Run Sixfab QMI installer, provide APN data00.telnyx, then start connectivity with quectel-CM. Optional auto-reconnect script available.
  - Sixfab Cellular IoT HAT (BG96, LTE-M/NB-IoT/EGPRS): Install Sixfab library and PPP installer, choose Cellular IoT HAT, APN data00.telnyx, no username/password, port ttyUSB3; connect with pon/poff. Expect lower throughput typical of Cat-M1.
- Nordic nRF9160 DK:
  - Update board and modem firmware via nRF Connect (Programmer → Erase & write; Update modem). Use LTE Link Monitor; device will issue AT commands and attach automatically.
- Particle Boron LTE:
  - Use Particle mobile app to activate, then enable third-party SIM: insert Telnyx SIM, update firmware via CLI (DFU mode), flash helper that sets APN/behavior for Telnyx, then restore default control and power cycle. Device will attach to Telnyx.

## Security and access patterns
- Public internet with static public IP per SIM: Enables inbound management, stable allowlisting, and device-hosted services.
- Private Wireless Gateway path: Keep devices off the public internet; route traffic into your VRF, across Cloud VPN/VXC, and control egress via your firewall or Telnyx-managed routing. Combine with wireless blocklists and traffic policy profiles for least-privilege connectivity.

## Messaging on mobile numbers
- Telnyx supports SMS/MMS on cellular numbers. A dedicated configuration page is forthcoming; manage messaging via the standard Telnyx messaging APIs once a Mobile Phone Number is assigned.
