# Telnyx Unified Glossary: AI, APIs, and Telecom

*Part 2 of 2 — see also: [Part 1](telnyx-unified-glossary-ai-apis-and-telecom--part-1.md)*

A single, consolidated glossary of AI, API, and telecom terms from Telnyx developer documentation—useful for builders working across AI agents, programmable communications, and networked applications.

## Telecom terms
- ACD — Average Call Duration; mean time a call lasts.
- ANI — Automatic Number Identification; identifies the caller’s number.
- ASR — Answer-Seizure Ratio; ratio of answered to attempted calls.
- B2BUA — Back-to-Back User Agent; VoIP architecture for media and signaling control.
- CDR — Call Detail Record; metadata for a telecom transaction.
- CLD — Calling Line Destination; identifies the called party’s number in VoIP setup.
- CLI — Calling Line Identification; displays the caller’s phone number.
- CNAM — Caller Name; displays the name associated with the caller’s number.
- CPE — Customer Premises Equipment; devices installed at a customer location.
- CPaaS — Communications Platform as a Service; telecom services via the cloud.
- Codec — Audio compression methods (e.g., G.711, G.729, Opus) used in VoIP.
- DID — Direct Inward Dialing; lets external callers reach an internal extension.
- DNIS — Dialed Number Identification Service; identifies the dialed number for routing inbound VoIP calls.
- DS0/DS1/DS3 — Digital Signal levels in T-carrier systems (e.g., DS1 = T1 line).
- DTLS — Datagram TLS; used in WebRTC encryption.
- DTMF — Dual Tone Multi-Frequency; signaling for dialing/input (touch-tone).
- E.164 — International telephone numbering standard.
- E911 — Enhanced 911; provides caller location to emergency services.
- ENUM — Telephone Number Mapping; converts phone numbers to Internet addresses.
- FAS — False Answer Supervision; fraudulent call charge without real connection.
- ICE — Interactive Connectivity Establishment; assists NAT traversal in VoIP.
- IVR — Interactive Voice Response; automated telephony for user interaction.
- Jitter — Variation in packet arrival time affecting voice quality.
- Jitter Buffer — Smooths audio variations in VoIP packets.
- LATA — Local Access and Transport Area; geographic area for call routing.
- LEC — Local Exchange Carrier; provides local phone service.
- LNP — Local Number Portability; keep numbers when changing providers.
- Latency — Delay between sending and receiving data.
- MOS — Mean Opinion Score; subjective voice quality rating (1–5).
- NPA-NXX — Numbering: NPA = area code; NXX = central office code.
- PBX — Private Branch Exchange; internal phone switching system.
- PDD — Post Dial Delay; time from call initiation to ringing.
- POTS — Plain Old Telephone Service; basic analog service.
- PRI — Primary Rate Interface; ISDN line with multiple voice/data channels.
- PSTN — Public Switched Telephone Network; circuit-switched network.
- QoS — Quality of Service; reliability and performance measures for telecom.
- RTP — Real-Time Transport Protocol; transmits audio/video streams.
- Rate Center — Geographic area determining local vs. long-distance calls.
- SBC — Session Border Controller; secures/manages VoIP traffic.
- SDC — Short Duration Calling; used in VoIP fraud detection and SIP trunk analysis.
- SHAKEN/STIR — Caller ID verification to prevent spoofing.
- SIP — Session Initiation Protocol; initiates and manages VoIP calls.
- SIP Proxy — SIP server routing/forwarding SIP requests, enforcing policy and facilitating setup.
- SIP Trunk — Virtual VoIP trunk line replacing traditional PRI.
- SIPS — SIP over TLS; secure VoIP signaling.
- SRTP — Secure RTP; encrypts RTP media streams.
- STUN/TURN — Servers supporting NAT traversal in real-time communications.
- T.38 — Protocol for Fax over IP (FoIP).
- TLS — Transport Layer Security; encrypts communications over IP.
- UCaaS — Unified Communications as a Service; integrated voice, video, messaging.
- VoIP — Voice over Internet Protocol; voice over IP networks.
- WebRTC — Web Real-Time Communication; browser-based real-time media exchange.
