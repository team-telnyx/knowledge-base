# Telnyx Unified Glossary: AI, APIs, and Telecom

*Part 1 of 2 — see also: [Part 2](telnyx-unified-glossary-ai-apis-and-telecom--part-2.md)*

A single, consolidated glossary of AI, API, and telecom terms from Telnyx developer documentation—useful for builders working across AI agents, programmable communications, and networked applications.

## AI terms
- AI Alignment — Ensuring AI behavior aligns with human goals and values.
- API Latency — Time delay between request and response in a deployed AI service.
- AUC (Area Under Curve) — Measure of a model’s ability to distinguish between classes.
- Accuracy — Proportion of correct predictions made by a model.
- Activation Function — Function introducing non-linearity into a neural network (e.g., ReLU, Sigmoid).
- Artificial Intelligence (AI) — Simulation of human intelligence in machines programmed to think and learn.
- Attention Mechanism — Enables models to focus on the most relevant parts of the input.
- Backpropagation — Algorithm for updating neural network weights.
- Batch Normalization — Normalizes activations to improve training speed and stability.
- Bias — Systematic error introduced by assumptions in data or model.
- Chain-of-Thought (CoT) — Technique where models generate intermediate reasoning steps.
- Computer Vision — Field enabling machines to interpret and decide based on visual data.
- Confusion Matrix — Table showing true vs. predicted classifications.
- Data Privacy — Protection of sensitive user data during training and usage.
- Deep Learning — ML subset using multi-layer neural networks to model complex patterns.
- Dropout — Regularization technique that randomly drops units during training.
- Embedding — Numerical representation of data, used for similarity or search.
- Epoch — One complete pass through the training dataset.
- Explainable AI (XAI) — Techniques to interpret and understand model predictions.
- F1 Score — Harmonic mean of precision and recall.
- Few-shot Learning — Learning from a small number of labeled examples.
- Fine-Tuning — Training a pre-trained model on a specific task or dataset.
- Generative AI — Models that generate new content (text, images, audio, code).
- Gradient Descent — Optimization algorithm minimizing a loss function.
- Hallucination — Fluent generated output that is factually incorrect.
- HuggingFace — Ecosystem for pretrained NLP models and transformers.
- Inference — Running a trained model to make predictions.
- LangChain — Framework for building LLM-powered applications via composable chains.
- Large Language Model (LLM) — Transformer-based model trained on large text corpora.
- LlamaIndex — Tool for indexing and querying external data with LLMs.
- LoRA (Low-Rank Adaptation) — Efficient fine-tuning method updating fewer parameters.
- Loss Function — Measures error between predictions and actual values.
- Machine Learning (ML) — AI subset where systems learn from data without explicit programming.
- Mixture of Experts — Architecture routing inputs through subsets of expert networks.
- Model Checkpointing — Saving model states during training to resume or analyze progress.
- Model Fairness — Ensuring performance does not discriminate against subgroups.
- Model Serving — Hosting and exposing ML models for inference.
- Multimodal AI — Models that process/generate multiple data types (text, image, audio).
- Natural Language Processing (NLP) — Understanding and generation of human language.
- Neural Network — Computational model inspired by the brain, core to deep learning.
- ONNX — Open Neural Network Exchange format for model interoperability.
- Open Weight Model — Model with publicly available weights for reuse and fine-tuning.
- Overfitting — Model learns training data too specifically and fails to generalize.
- Positional Encoding — Injects token position information into transformer models.
- Pre-training — Initial training on a large, generic dataset.
- Precision — Proportion of true positives among all positive predictions.
- Prompt Engineering — Crafting prompts to guide LLM responses.
- Proprietary Model — Model with restricted access, typically hosted by a company.
- PyTorch — Popular deep learning library.
- ROC Curve — Plot showing classification performance across thresholds.
- Recall — Proportion of true positives among all actual positives.
- Reinforcement Learning — Agents learn via actions and rewards.
- Residual Connection — Skip connections that help prevent vanishing gradients.
- Responsible AI — Ethical and accountable AI development and deployment.
- Retrieval-Augmented Generation (RAG) — Augments prompts with retrieved context from a document store.
- Scikit-learn — Python library for traditional ML.
- Self-Attention — Weighs importance of different parts of an input sequence.
- Semi-Supervised Learning — Combines small labeled with large unlabeled datasets.
- Supervised Learning — Training on labeled data.
- TensorFlow — Open-source deep learning framework by Google.
- TensorRT — NVIDIA platform for optimizing and deploying deep learning models.
- Tokenization — Splitting text into tokens for processing.
- Transformer — Architecture using self-attention for sequence tasks.
- Underfitting — Model too simple to capture underlying patterns.
- Unsupervised Learning — Learning patterns from unlabeled data.
- Variance — Sensitivity to small fluctuations in training data.
- Vector Database — Database optimized for high-dimensional embeddings.
- Zero-shot Learning — Predicting on tasks without labeled examples.

## API terms
- API (Application Programming Interface) — Rules enabling software applications to communicate.
- API Documentation — Instructions and details on how to use an API.
- API Key — Token in an API call that authenticates the client.
- Basic Auth — Authentication using a base64-encoded username and password.
- Bearer Token — Access token used in the Authorization header.
- DELETE — HTTP method to delete a resource.
- Endpoint — Specific URL where an API accesses resources.
- Form Data — Key-value encoding for sending data, often with file uploads.
- GET — HTTP method to retrieve data.
- GraphQL — Query language for APIs enabling clients to request specific data.
- gRPC — High-performance, open-source RPC framework by Google.
- HTTP — Hypertext Transfer Protocol, foundation of API communication.
- HTTPS — Secure HTTP using encryption.
- Header — HTTP metadata key-value pairs in requests/responses.
- Idempotency — Operation property yielding the same result when applied repeatedly.
- JSON — Lightweight data format for API communication.
- JWT (JSON Web Token) — Compact, self-contained method to securely transmit information.
- Multipart — Form data type allowing multiple files/fields in one request.
- OAuth — Open-standard protocol for authorization.
- OpenAPI — Specification for describing RESTful APIs.
- PATCH — HTTP method for partial updates to a resource.
- POST — HTTP method to send data to a server.
- PUT — HTTP method to update an existing resource.
- Pagination — Splitting responses into smaller pages.
- Payload — Actual data sent in a request or returned in a response.
- REST — Representational State Transfer architecture for stateless communication.
- RESTful API — API that adheres to REST principles.
- Rate Limiting — Restricting the number of API calls a client can make.
- Request — Action initiated by a client to an API server.
- Resource — Object or representation accessible via an API.
- Response — Data returned by the server after processing a request.
- Route — Path portion of a URL to access a resource (excluding domain/protocol).
- SDK (Software Development Kit) — Tools for building applications with an API.
- Status Code — Number indicating result of an HTTP request (e.g., 200, 404, 500).
- Swagger — Tools for developing/documenting OpenAPI specs.
- Throttling — Intentionally slowing the response rate from an API.
- Versioning — Maintaining multiple iterations of an API (e.g., v1, v2).
- Webhooks — Server-to-client callbacks when events occur.
- XML — Extensible Markup Language data format used by some APIs.
